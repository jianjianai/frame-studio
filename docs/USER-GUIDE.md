# 使用指南

## 界面

```
┌ 标题栏：作品名（双击重命名） · 分支 ·              [侧栏][面板][AI] [导出] ┐
│活│ 侧边栏        │ 预览（可在右侧打开文件）            │ AI 聊天        │
│动│ 资源/素材/     │                                     │                │
│栏│ 音频/版本/导出 ├─────────────────────────────────────┤                │
│  │               │ 时间轴 · 问题 · 任务                 │                │
└ 状态栏：分支与未保存数 · 检查结果 · 播放位置 · 分辨率 · 连接 ───────────────┘
```

快捷键：空格 播放/暂停 · ←/→ 逐帧（Shift 跳 1 秒）· Home 回到开头 · Ctrl+B 侧边栏 · Ctrl+J 底部面板 · Ctrl+I 聚焦 AI 输入框 · Ctrl+S 保存文件。

## 创建作品

首页 →「新建作品」：

- **AI 制作**：写下想要的视频（内容、风格、时长、画幅），创建后自动交给 AI 开始制作。
- **空白作品**：得到一个只有标题图层的作品，自己添加素材或稍后让 AI 制作。

## 和 AI 一起制作

右侧聊天面板：

- 直接描述修改：“开场标题再大一点，2 秒处加一个闪白转场”。
- 📷 把当前画面作为图片发给 AI；🕒 引用当前时间。时间轴图层右键「让 AI 修改这里」可以引用图层或片段；问题面板可以一键交给 AI 修复。
- AI 回复中的时间（如 0:12.5）可以点击跳转，文件名可以点击打开。
- 每轮修改结束会自动保存版本，消息下方「撤销这一轮」可恢复到修改前。
- AI 工作时可以继续发消息（排队），也可以点停止。
- 底部选择 AI 配置、模型、模式（Claude 的“接受编辑 / 计划 / 手动确认”等）与思考强度。遇到需要确认的操作（如运行命令），聊天中会出现确认卡片。
- 历史对话在标题处的下拉列表中。

## 预览

- 保存后立即更新，不刷新、不跳回开头。更新失败会保留上一个可用画面并显示原因。
- 画质：流畅 / 标准 / 高清，只影响预览；导出始终是高清。
- 加载失败时可点「让 AI 修复」。

## 时间轴（简单编辑）

- 拖动片段移动，拖两端裁剪；右键：在播放头处切开、隐藏/静音、删除、让 AI 修改。
- 「+ 字幕」在播放头处添加字幕，双击字幕编辑文字与时间。「标记」添加镜头标记。
- 音频片段显示波形；音轨名旁可静音整条音轨。
- Ctrl+滚轮缩放时间轴。

## 录音

在播放器工具条或「音频」侧栏点麦克风：作品会从播放头开始播放，同时录音；再点一次停止，录音自动放到「录音」音轨的对应位置。建议戴耳机，避免录进作品的声音。远程访问时需要 HTTPS 才能使用麦克风。

## 配音

「音频」侧栏 → 配音：输入文字，选择引擎和声音，生成试听，满意后「放到播放头」。没有可用引擎时在 设置 → 语音 中：

- Edge 在线语音：免费，需要联网。
- 本地模型：一键下载后离线使用（推荐 Kokoro 多语言）。
- OpenAI 兼容接口：OpenAI TTS 或自建服务。

## 素材

「素材」侧栏：拖入文件上传到作品 `public/`；从网址导入；双击素材加到画面（图片/视频成为图层，音频放到音轨）；右键可引用给 AI、复制引用地址、存入素材库。

素材库在同一作品库的所有作品间共享（`frame/materials` 分支，可同步到 GitHub）。

## 版本与 GitHub

「版本」侧栏：查看未保存的修改和差异、保存版本、查看历史、恢复到任意版本（恢复会生成新版本，不会丢失历史）。

作品库可以连接 GitHub：首页「连接 GitHub 作品库」添加已有仓库或新建仓库，或把本地作品库发布到 GitHub。每个作品是独立分支，推送/拉取互不影响。GitHub 账号在 设置 → GitHub 中用个人访问令牌添加。

## 导出

「导出」侧栏：选择分辨率、帧率、范围和是否烧录字幕，导出 MP4（H.264 + AAC）。导出使用点击时的作品快照，导出期间可继续修改。也可以下载当前帧 PNG 和字幕 SRT。

## 回收站

首页作品卡片菜单「移到回收站」。回收站可以恢复或永久删除（只删除本机分支，GitHub 上的分支不受影响）。
