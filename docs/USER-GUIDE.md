# 使用指南

## 界面

```
┌ 标题栏：作品名（双击重命名） · 分支 ·              [侧栏][面板][AI] [导出] ┐
│活│ 侧边栏        │ [预览][文件…] 选项卡                │ AI 聊天        │
│动│ 资源/素材/     │                                     │                │
│栏│ 音频/版本/导出 ├─────────────────────────────────────┤                │
│  │               │ 时间轴 · 问题 · 任务                 │                │
└ 状态栏：分支与未保存数 · 检查结果 · 播放位置 · 分辨率 · 连接 ───────────────┘
```

编辑区和 VS Code 一样：「预览」是第一个选项卡，打开的文件和素材以选项卡显示在它旁边，点选项卡切换；切到文件时预览仍在后台运行（播放不中断），关闭全部文件回到预览。在「资源管理器」或「素材」中单击文件（代码、文本、图片、音视频都一样）打开的是预览选项卡：标题为斜体，会被下一次单击的文件替换；双击文件或选项卡、或者编辑内容后，选项卡保持打开。中键点击选项卡关闭。

快捷键：空格 播放/暂停 · ←/→ 逐帧（Shift 跳 1 秒）· Home 回到开头 · Ctrl+B 侧边栏 · Ctrl+J 底部面板 · Ctrl+I 聚焦 AI 输入框 · Ctrl+S 保存文件。

## 创建作品

首页 →「新建作品」：

- **AI 制作**：写下想要的视频（内容、风格、时长、画幅），创建后自动交给 AI 开始制作。
- **空白作品**：得到一个只有标题图层的作品，自己添加素材或稍后让 AI 制作。

## 和 AI 一起制作

右侧聊天面板：

- 直接描述修改：“开场标题再大一点，2 秒处加一个闪白转场”。
- 📷 把当前画面作为图片发给 AI；🕒 引用当前时间。时间轴图层右键「让 AI 修改这里」可以引用图层或片段；问题面板可以一键交给 AI 修复。
- AI 回复中的时间（如 0:12.5）可以点击跳转，文件名可以点击打开。
- 版本不会自动保存：在左侧「版本与同步」中查看改动并手动保存，活动栏的版本图标会显示未保存的改动数。
- AI 工作时可以继续发消息（排队）；排队的消息点「引导」会立即插入 AI 正在进行的这一轮，不用等它做完。也可以点停止。
- 选择的 AI、模型、模式与思考强度会被记住，刷新页面或服务重启后保持不变。
- 底部选择 AI 配置、模型、模式（Claude 的“接受编辑 / 计划 / 手动确认”等）与思考强度。遇到需要确认的操作（如运行命令），聊天中会出现确认卡片。
- 历史对话在标题处的下拉列表中。

## 预览

- 保存后立即更新，不刷新、不跳回开头。更新失败会保留上一个可用画面并显示原因。
- 画质：流畅 / 标准 / 高清，只影响预览；导出始终是高清。
- 加载失败时可点「让 AI 修复」。
- 素材预缓存：打开作品后，浏览器会把作品 `public/` 里的全部素材下载到本地缓存，窗口顶部的细进度条显示进度（鼠标悬停可看文件数和大小）。之后预览直接从本地读取，不再因网络卡顿；素材改动后只重新下载改动的文件。需要通过 https 或本机地址访问（浏览器限制）。

## 时间轴

- 拖动片段移动，拖两端裁剪，会吸附到播放头和其他片段的边缘（按住 Alt 不吸附）；右键：在播放头处切开、隐藏/静音、音量、删除、让 AI 修改。选中后按 Delete 删除。
- **撤销**：时间轴上的每一次修改都可以用 Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做，工具栏也有按钮。如果之后 AI 改过同一份文件，撤销会被拒绝，以免覆盖 AI 的修改。
- **放入素材**：把左侧「素材」中的文件拖到时间轴。图片/视频放到所拖到的图层上方（或拖到「新图层」）；音频放到所拖到的音轨（或拖到「新音轨」）。
- **音轨**：「+ 音轨」新建；音轨名右键可重命名、调整音量、静音、删除。
- **音量**：音轨名旁的 dB 数字点开是推子；选中音频片段（或带原声的视频图层）时，工具栏显示它的音量推子。拖动时即时试听，松开后保存，双击恢复 0 dB。
- 「+ 字幕」在播放头处添加字幕，双击字幕编辑文字与时间。「标记」添加镜头标记。
- **缩放与滚动**（与剪辑软件一致）：Ctrl/Alt + 滚轮（或触控板双指捏合）以鼠标位置为中心缩放；滚轮上下滚动轨道（轨道不多时左右滚动），Shift + 滚轮左右滚动；按住中键拖动平移；`=` / `-` 放大缩小，`\` 适应宽度；工具栏有缩放滑块。放大到足够大时刻度显示到帧。播放时视图自动跟随播放头。
- 拖动刻度尺或播放头顶部的手柄定位，拖动不会选中文字。

## 录音

在播放器工具条或「音频」侧栏点麦克风：作品会从播放头开始播放，同时录音；再点一次停止，录音自动放到「录音」音轨的对应位置。建议戴耳机，避免录进作品的声音。远程访问时需要 HTTPS 才能使用麦克风。

## 配音

「音频」侧栏 → 配音：输入文字，选择引擎和声音，生成试听，满意后「放到播放头」。没有可用引擎时在 设置 → 语音 中：

- Edge 在线语音：免费，需要联网。
- 本地模型：一键下载后离线使用（推荐 Kokoro 多语言）。
- OpenAI 兼容接口：OpenAI TTS 或自建服务。

## 素材

「素材」侧栏：拖入文件上传到作品 `public/`；从网址导入；单击素材在编辑区打开预览选项卡（和 VS Code 一样，下一次单击会替换它，双击则保持打开），可查看尺寸、时长并引用给 AI；把素材拖到时间轴即可使用；右键可添加到播放头处、引用给 AI、复制引用地址、存入素材库。

素材库在同一作品库的所有作品间共享（`frame/materials` 分支，可同步到 GitHub）。

## 版本与 GitHub

「版本」侧栏：查看未保存的修改和差异、保存版本、查看历史、恢复到任意版本（恢复会生成新版本，不会丢失历史）。

作品库可以连接 GitHub：首页「连接 GitHub 作品库」添加已有仓库或新建仓库，或把本地作品库发布到 GitHub。每个作品是独立分支，推送/拉取互不影响。GitHub 账号在 设置 → GitHub 中用个人访问令牌添加。

## 导出

「导出」侧栏：选择分辨率、帧率、范围和是否烧录字幕，导出 MP4（H.264 + AAC）。导出使用点击时的作品快照，导出期间可继续修改。也可以下载当前帧 PNG 和字幕 SRT。

## 回收站

首页作品卡片菜单「移到回收站」。回收站可以恢复或永久删除（只删除本机分支，GitHub 上的分支不受影响）。
