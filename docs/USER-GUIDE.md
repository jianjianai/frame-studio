# 使用指南

## 界面

```
┌ 标题栏：作品名（双击重命名） · 分支 ·   [侧栏][面板][AI] [发布][复盘][导出] ┐
│活│ 侧边栏         │ [预览][文件…][导出][素材库…] 选项卡  │ AI 聊天        │
│动│ 资源管理器/素材/ │                                     │                │
│栏│ 经验库/版本/属性/├─────────────────────────────────────┤                │
│  │ 提示词/音频      │ 时间轴 · 问题 · 任务                 │                │
└ 状态栏：分支与未保存数 · 检查结果 · 播放位置 · 分辨率 · 连接 ───────────────┘
```

活动栏从上到下：资源管理器、素材、经验库、版本与同步、属性、提示词、音频与配音，各自在侧边栏显示。选项多、要编辑或数据多的放在编辑区的选项卡里，有足够的宽度：标题栏右上角的「复盘」「导出」，素材库和经验库的「管理…」，素材侧栏的「资源」。

编辑区和 VS Code 一样：「预览」是第一个选项卡，打开的文件和素材以选项卡显示在它旁边，点选项卡切换；切到文件时预览仍在后台运行（播放不中断），关闭全部文件回到预览。切换选项卡不会重新加载：每个选项卡保持原样（SVG 编辑器、滚动位置、视频播放到的位置都在），直到关闭它；切走时音视频和动画暂停。选项卡多了会变窄，长标题截断显示（鼠标停在上面看全名）；仍放不下时右侧出现左右翻页按钮，也可以在选项卡上滚动鼠标滚轮或用手指左右滑动，拖着选项卡停在翻页按钮上会往那边滚动。当前选项卡总会滚到看得见的位置。刷新浏览器后，打开的选项卡、拆分布局和未保存的修改都会恢复（每个作品分别记在这个浏览器里）；未保存期间文件被 AI 或别处改过时，会提示选择保留哪个版本。在「资源管理器」「素材」「资源」「经验库」「版本与同步」等处单击文件（代码、文本、图片、音视频、SVG、资源、改动都一样），每个都在自己的新选项卡里打开（排在当前选项卡右边），不会替换已经打开的选项卡；已经打开的再点一次只是切过去。中键点击选项卡关闭。

「资源管理器」可以多选：Ctrl（Mac 上 ⌘）点击加选或取消，Shift 点击选中一段；触屏上长按文件选「加入选择」。选中后点标题栏的下载按钮，或右键（长按）→「导出选中的 N 项」下载到本机：单个文件直接下载，多个文件或文件夹打包成 zip（同一文件夹里的文件解压后不带外层文件夹；单个 zip 不超过 4 GB）。右键菜单也可以对选中的内容一起引用到 AI 聊天或删除。

点过预览画面后快捷键照常可用（空格、方向键、Ctrl+Z 等）。

**放大查看**：预览画面（包括样片）和图片选项卡可以像看图软件一样放大：Ctrl/⌘/Alt + 滚轮（或触控板、触屏双指捏合）以指针处为中心缩放；放大后拖动画面（或用滚轮）移动；双击（触屏双击）在适应窗口和原始大小之间切换。画面右上角显示缩放比例和「适应」按钮；点过画面后 Ctrl + = / Ctrl + - 放大缩小，Ctrl + 0 恢复。预览的 100% 指作品本身的分辨率，要看清细节可把画质切到「高清」；预览工具栏的放大镜按钮也可以切换。放大只影响查看，不改变作品和截图。

快捷键：空格 播放/暂停 · ←/→ 逐帧（Shift 跳 1 秒）· Home 回到开头 · Ctrl+B 侧边栏 · Ctrl+J 底部面板 · Ctrl+I 聚焦 AI 输入框 · Ctrl+S 保存文件。

## 创建作品

首页 →「新建作品」：填写名称，选择画幅、时长、帧率和作品库，得到一个只有标题图层的作品。之后在右侧聊天里告诉 AI 想做什么，或自己添加素材。

作品卡片菜单 →「创建副本」：用作品现在的样子（包括未保存的修改）新建一个作品，历史从副本开始，原作品不受影响。

## 封面

首页卡片显示作品的封面：

- **自动**（默认）：FRAME 从作品中截取一帧，挑一个画面饱满的时刻（避开黑场和空白画面）。作品改动后，回到首页时封面会在后台重新截取，几秒后自动换上；首页开着时，AI 改了作品也会跟着更新。
- **指定画面**：预览栏的「设为封面」按钮（相机按钮旁）把正在显示的画面设为封面。以后作品改动时，封面跟着这一秒的画面更新。
- **上传图片**：属性 → 封面 →「上传图片…」，或首页卡片菜单「上传封面图片…」。图片保存为作品的 `public/poster.webp`，之后不再自动截取。
- 属性 → 封面 →「自动选取」恢复自动。封面设置记在 `project.ts`（`posterTime`、`poster`）中，和其他修改一样需要保存版本；也可以让 AI 设置（「把第 12 秒设为封面」）。已发布的作品不能更换封面。
- 截取的封面缓存在本机（数据目录 `cache/covers/`），释放本地空间后首页仍显示最后的封面。

## 和 AI 一起制作

右侧聊天面板：

- 直接描述修改：“开场标题再大一点，2 秒处加一个闪白转场”。
- **语音输入**：点输入框右下角的麦克风说话，文字边说边出现在光标处；说完点红色的计时按钮或按 Enter，文字留在输入框里，改好再发送（不会自动发出）；按 Esc 取消，输入框恢复原样。没有出字时会说明原因（麦克风没有声音、没听到说话等）。识别模型 SenseVoice 在服务器上离线运行（Docker 镜像自带；从源码运行时第一次使用会提示下载，约 160 MB），中文、英文、粤语、日语、韩语可以混着说，自带标点；也可以在 设置 → 语音 改用 OpenAI 兼容的识别接口（每句说完才出字）。远程访问时需要 HTTPS。
- 📷 把当前画面作为图片发给 AI；🕒 引用当前时间。时间轴图层右键「让 AI 修改这里」可以引用图层或片段；问题面板可以一键交给 AI 修复。
- AI 回复中的时间（如 0:12.5）可以点击跳转，文件名可以点击打开。
- 版本不会自动保存：在「版本与同步」里查看改动并手动保存；活动栏的版本与同步图标显示未保存的改动数。
- 作品的 `AGENTS.md` 是给 AI 的需求和约定。AI 每次对话开始时只知道它在哪、有多大，开始工作前自己去读；内容由 AI 来保持整洁、精练（历史、被否的方案、详细分镜可以放到 `production/` 下）。
- AI 工作时可以继续发消息（排队）；排队的消息点「引导」会立即插入 AI 正在进行的这一轮，不用等它做完。也可以点停止。
- 选择的 AI、模型、模式与思考强度会被记住，刷新页面或服务重启后保持不变。
- **用你电脑的显卡画**：AI 查看画面、测渲染速度、检查动作，以及查看这个作品里的三维模型时，改在开着这个作品的电脑上用浏览器的显卡画，三维作品也很快（用的是浏览器已经为这个作品保存的素材，不会多下载；作品没用到的素材库模型、缩略图还在服务器上画）；工作台状态栏一直显示这台电脑用哪张显卡（不用这台电脑时显示「服务器渲染」），AI 正在用它画时变成「AI 在用本机显卡画」；这时你播放预览，AI 每画一帧都先让预览画一帧，预览不会整段卡住，但 AI 的检查会慢一些（想让它快点就先暂停预览）；点它可以改设置。几台电脑都开着同一个作品时，先用给这个对话发消息的人的；作品没在哪里开着时，用发消息的那个浏览器（开着 FRAME 的任何页面）；都没有就在服务器上画（没有显卡，三维作品慢很多）。不想用自己的电脑：设置 → AI → 偏好 里选「服务器 CPU」，这台设备就不画，你在这个浏览器里发消息的对话也都在服务器上画。这个选择只对当前浏览器有效；手机、平板和没有显卡加速的浏览器本来就不画。
- 底部选择 AI 配置、模型、模式（Claude 的“接受编辑 / 计划 / 手动确认”等）与思考强度。遇到需要确认的操作（如运行命令），聊天中会出现确认卡片；手动确认模式下，AI 用 FRAME 工具修改作品前也会请求确认。
- 一个对话固定使用一个 AI 配置（以及自定义 API 的一个模型）：在对话中选择其他 AI，会直接新建一个使用它的对话，原对话保留，输入框里写好的内容也保留。同一个账号的模型、模式和思考强度可以随时切换，立即生效。
- **上下文**：输入框右下角的圆圈显示 AI 的上下文用了多少，越满颜色越深。快满时 AI 会自动压缩；点圆圈可以查看用量并手动「压缩上下文」（AI 把之前的对话总结成摘要后继续）。
- **分支与编辑**：鼠标移到自己发的消息上点铅笔可以修改它重新发送；AI 回复下方的「从这里分支」新建一个包含到这里为止内容的对话，从这里换个方向继续。两种方式都会新建分支对话（AI 的记忆也从那里分叉），原对话保留；同一处有多个版本时，消息下方的「‹ 1/2 ›」可以切换。分支只分叉对话，作品文件不会回退。
- **提示词库**：输入框下方的书签按钮列出常用提示词，点击放进输入框；也可以把输入框里写好的内容存为提示词。左侧活动栏「提示词」里像收藏夹一样整理：新建文件夹、拖动排序或移进文件夹、右键编辑和删除。提示词库所有作品共用。
- 历史对话在标题处的下拉列表中，点其他地方或按 Esc 关闭；分支对话带分支图标。很长的对话先显示最近几轮，往上滚动（或点顶部的「更早的对话」）再载入之前的；工具卡片展开时才载入完整输出；很长的输出先显示开头，下方写明「已截断，还有多少行没有显示」，点「展开全部」查看完整内容。

## 预览

- 保存后立即更新，不刷新、不跳回开头。更新失败会保留上一个可用画面并显示原因。
- 画质：流畅 / 标准 / 高清，只影响预览；导出始终是高清。
- 加载失败时可点「让 AI 修复」。
- 本地缓存：打开作品后，浏览器会把作品播放要用的素材（作品 `public/` 里的全部文件，以及用到的素材库文件）下载到本地缓存，窗口顶部的细进度条显示进度（鼠标悬停可看文件数和大小）。预览的代码也保存在本地。之后预览和编辑器选项卡里打开的这些文件都直接从本地读取，不再因网络卡顿；再次打开作品时，没改过的代码和素材不再向服务器请求，只下载改动过的，网络延迟高时也能很快打开。需要通过 https 或本机地址访问（浏览器限制）。

## 时间轴

- 拖动片段移动，拖两端裁剪，会吸附到播放头和其他片段的边缘（按住 Alt 不吸附）；右键：在播放头处切开、隐藏/静音、音量、删除、让 AI 修改。选中后按 Delete 删除。
- **撤销**：时间轴上的每一次修改都可以用 Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做，工具栏也有按钮。如果之后 AI 改过同一份文件，撤销会被拒绝，以免覆盖 AI 的修改。
- **放入素材**：把「素材」侧栏中的文件拖到时间轴（触屏上长按素材选「添加到画面」或「放到音轨」，放在播放头处）。图片/视频放到所拖到的图层上方（或拖到「新图层」）；音频放到所拖到的音轨（或拖到「新音轨」）。
- **音轨**：「+ 音轨」新建；音轨名右键可重命名、调整音量、静音、删除。
- **音量**：音轨名旁的 dB 数字点开是推子；选中音频片段（或带原声的视频图层）时，工具栏显示它的音量推子。拖动时即时试听，松开后保存，双击恢复 0 dB。
- 「+ 字幕」在播放头处添加字幕，双击字幕编辑文字与时间。「标记」添加镜头标记。
- **缩放与滚动**（与剪辑软件一致）：Ctrl/Alt + 滚轮（或触控板双指捏合）以鼠标位置为中心缩放；滚轮上下滚动轨道（轨道不多时左右滚动），Shift + 滚轮左右滚动；按住中键拖动平移；`=` / `-` 放大缩小，`\` 适应宽度；工具栏有缩放滑块。放大到足够大时刻度显示到帧。播放时视图自动跟随播放头。
- 拖动刻度尺或播放头顶部的手柄定位，拖动不会选中文字。
- **作品时长**：时间轴上作品结束的位置有一条「结束」竖线，之后的区域为斜纹。拖动刻度尺上的「结束」手柄即可加长或缩短作品（吸附到播放头和片段边缘，按帧取整）；不能短于最后一个片段，需要更短时先裁剪片段。可以撤销。

## 属性

活动栏的「属性」（侧边栏，调整时预览就在旁边）：在时间轴上选中对象后，这里显示它可以修改的属性，改完回车或离开输入框即保存，每次修改都能用 Ctrl+Z 撤销。双击时间轴上的对象、或右键「属性」会直接打开这里。

- **图层**：名称、来源、颜色（纯色图层）、显示/隐藏；开始、时长、素材起点、速度、循环；位置与大小（X/Y/宽/高，占画面的百分比）、旋转、不透明度、适应方式、混合模式；淡入淡出；视频原声的开关、音量和静音；代码场景的参数。有关键帧动画的属性显示关键帧个数，可以改为固定值。
- **音频片段**：名称、所在音轨（可移到其他音轨）、开始、时长、素材起点、速度、保持音高、移调、循环、音量（dB，拖动即时试听）、声像、静音、淡入淡出。
- **音轨**（点击音轨名选中）：名称、音量、声像、静音。
- **字幕**：文字、开始、结束。**镜头标记**：名称、说明、时间。
- 没有选中任何对象时显示作品的标题、说明、时长、帧率和封面（见「封面」）。

## 录音

在播放器工具条或「音频与配音」侧栏点麦克风：作品会从播放头开始播放，同时录音；再点一次停止，录音自动放到「录音」音轨的对应位置。建议戴耳机，避免录进作品的声音。远程访问时需要 HTTPS 才能使用麦克风。

## 配音

「音频与配音」侧栏 → 配音：输入文字，选择引擎和声音，生成试听，满意后「放到播放头」。没有可用引擎时在 设置 → 语音 中：

- Edge 在线语音：免费，需要联网。
- 本地模型：一键下载后离线使用（推荐 Kokoro 多语言）。
- OpenAI 兼容接口：OpenAI TTS 或自建服务。

## 经验库

经验库是同类作品共用的制作经验，比如“知识类视频”“音乐视频”。它就是一个 Markdown 文档文件夹，和作品放在同一个作品库里。每个经验库是一个独立的分支（`experience/<id>`），版本、未保存的修改和 GitHub 同步各管各的。

- **侧边栏**：活动栏「经验库」只列出本作品关联的经验库和其中的文档，可以同时用多个（例如“通用规范”加“竖屏短片”）。
- **管理（选项卡）**：点「管理…」打开「经验库」选项卡：搜索名称、介绍或所有经验库里的文档；按「适合本作品」「用得最多」「最近用过」「名称」排序；筛选「全部」「本作品」「推荐」「回收站」；每个经验库一行，「关联」「取消关联」，展开看里面的文档。适合本作品的会写明理由（名称、介绍或内容相近，或同一系列、类似的作品在用，例如「数学：三角函数」会推荐「数学：勾股定理」用的经验库）。搜不到时可以直接新建。
- **删除与回收站**：在选项卡里点经验库的「⋯」→「删除（移到回收站）」。它连同未保存的修改一起保存，分支改名为 `experience-trash/<名称>`（GitHub 上一起改），其他经验库不受影响；回收站里的经验库可以恢复（id 已被占用时自动换一个），或彻底删除（分支和全部版本一起删除，不能找回）。首页的「回收站」也能看到它们。
- **id 与名称**：新建时由名称得到 id（分支名的最后一段，空格等分支名不允许的字符换成「-」），之后不再改变；作品按 id 关联经验库。
- **重命名**：选项卡里经验库的「⋯」→「重命名」，只改显示的名称（README 的标题），id 不变，关联它的作品不受影响；改名立即保存为一个版本，其他未保存的修改保持未保存。
- **AI 怎么读**：AI 对话开始时只知道作品关联了哪些经验库，需要时自己读（先看 README 和目录）。经验库的结构由 AI 决定，整理、精简和把太长的文档拆开也由它自己负责，没有大小限制；README 的第一个「# 」标题始终是经验库的名称。
- **AI 记在哪里**：你纠正它、确认了某种做法或解决了难题时，AI 记下来，放在哪里由它判断：只和这个作品有关的写进作品的 `AGENTS.md`；可以复用、关联的经验库又适合的，写进经验库；可以复用但没有合适经验库的，先记在作品的 `经验.md`（「经验」面板显示“本作品记下的经验 N 条，待整理”）。点「让 AI 整理经验」，AI 会把 `经验.md` 里的条目合并进合适的经验库（没有合适的会建议放哪个或新建，你同意后才关联或新建）。AI 不会自己关联或新建经验库。
- **自动保存**：AI 改的经验库在它每次回复结束时自动保存为一个版本（版本说明是它写的一句话），你在「版本与同步」里可以按经验库查看和恢复。你自己在工作台里改的经验文档仍是未保存状态，在「版本与同步」里保存，或让 AI 保存。
- **查看与编辑**：文档在编辑区以选项卡打开，默认显示排版后的样子，右上角切换「编辑」「预览」，Ctrl+S 保存。右键（触屏上长按）可以新建文档、重命名、删除，或把文档引用到 AI 聊天，和 AI 一起改。
- **版本**：在「版本与同步」里展开「经验库」（只列出本作品关联的），选其中一个经验库，查看它的改动、保存版本、恢复历史、和 GitHub 同步，只影响这一个经验库。选项卡里经验库的「⋯」→「版本与同步」直接跳到它。

## 素材

「素材」侧栏：拖入文件上传到作品 `public/`；从网址导入；单击素材在编辑区的新选项卡里打开，可查看尺寸、时长并引用给 AI；把素材拖到时间轴即可使用；右键（触屏上长按，或点卡片右上角的「⋯」）可添加到播放头处、引用给 AI、复制引用地址、存入素材库。标题栏的「资源」按钮在选项卡中打开素材库里声明的角色、场景、效果、音效等。

## 浏览器（网站登录）

有些素材要登录才能下载（Sketchfab 模型、素材站），有些网站会拦下服务器的请求（YouTube 要求“确认你不是机器人”，B 站登录后才有高清）。FRAME 自带一个运行在服务器上的浏览器，在里面登录过的网站一直保持登录，AI 就能用这个登录状态浏览和下载。

每个作品库有自己的浏览器：在一个作品库里登录的网站，只有这个作品库的作品和 AI 能用，别的作品库看不到（选项卡右上角写着是哪个作品库的浏览器）。不同作品库用不同账号时，各自登录即可。注意 FRAME 只有一个密码：知道密码的人都能打开任何作品库，也就能用它的浏览器。

- **打开**：「素材」侧栏标题栏的地球按钮，在编辑区的选项卡里打开。AI 需要你登录时，聊天里会出现「AI 请你登录 …」卡片，点「打开浏览器」直接跳到那个网站。
- **使用**：和普通浏览器一样点击、滚动、打字（中文输入法、粘贴都可以），顶部有标签页、前进后退和地址栏。触屏上点一下是点击，拖动是滚动，需要打字时点「键盘」按钮。扫码登录、密码、验证码、“我不是机器人”都在这里自己完成，不要发到聊天里。
- **登录好了**：点聊天卡片或浏览器顶部提示里的「登录好了」，AI 会收到消息接着做。
- **看 AI 在做什么**：AI 的标签页带 ✦ 标记，它正在用的标签页顶部会提示。每个 AI 对话用自己的标签页。
- **AI 能做什么**：只浏览、搜索、翻页和下载。它不会填账号密码、不会在评论框里写东西，也不会发帖、点赞、关注、购买或改账号设置；需要这些时由你自己在浏览器里操作。YouTube 这类网站，AI 会把登录信息交给下载程序（yt-dlp），文件一小时后自动删除。
- **下载**：你在浏览器里点的下载显示在选项卡底部，可以「存到本机」或「放进作品」（作品的 `public/imports/`）。保留一小时。
- **退出登录**：右上角「⋯」→「退出 <网站>」清除这个网站的登录信息；「清除全部登录信息…」清除这个作品库的浏览器里所有网站的登录、浏览记录和缓存。取消链接作品库时，它的浏览器资料一起删除。
- 服务器部署（设置了密码）时，这个浏览器只能访问公网，不能访问服务器所在的内网。15 分钟没人用会自动关闭，登录状态保留。建议用小号登录：网站可能限制或封禁频繁下载的账号。

### 用电脑上的 Edge / Chrome（FRAME 连接器）

也可以让 AI 直接用你电脑上的浏览器：你在那里已经登录的网站，AI 不用再登录，登录信息也不会传到服务器。只要电脑上的浏览器连着，AI 就优先用它；没连着（比如你在手机上）时用上面那个服务器上的浏览器。

1. 「浏览器」标签页顶部点「连接电脑上的浏览器」，下载 `frame-connector.zip`，右键「全部解压缩」（得到的 `frame-connector` 文件夹里直接就是 `manifest.json`）。
2. Edge 打开 `edge://extensions`（Chrome 是 `chrome://extensions`；对话框里可以复制这个地址），打开「开发人员模式」，点「加载解压缩的扩展」，选解压出的文件夹（提示“清单文件丢失”时多半是选了外面一层）。
3. 回到 FRAME：对话框会自动发现扩展装好了（不用刷新），点「一键连接这个浏览器」。会打开一个页面，连好后它自己关闭。

连接的是当前这个作品库；在别的作品库里再点一次「一键连接」，它们就共用这个浏览器里的登录。扩展装在另一个浏览器里时，用对话框底部的「手动配对」：在扩展图标里填地址和配对码（10 分钟内有效，用一次）。浏览器不允许网页替你装扩展，所以第 1、2 步只能手动做一次；以后上架 Edge 加载项商店，就能在商店里一键安装。

AI 能用的只有两种标签页：它自己开的（在单独的窗口里，标签组名为「FRAME AI」），和你交给它的（在要给它看的页面上点扩展图标 →「让 AI 使用这个页面」，在同一个地方「收回」）。你没交出去的标签页它看不到也动不了。规则和服务器上的浏览器一样：只浏览和下载，不填密码、不写评论、不发帖、不点赞关注、不买东西；AI 请你登录时，那个页面会切到你面前，登录好后点聊天卡片或「浏览器」标签页里的「登录好了」。

- AI 在操作网页时，浏览器顶部会出现“FRAME 连接器 已开始调试此浏览器”的提示，这是扩展在控制它开的页面；点「取消」会让 AI 这次操作失败。
- 下载时，扩展只把你的登录信息带给 AI 的标签页正在访问的网站。YouTube 这类要用 yt-dlp 的视频，电脑上的登录不会传到服务器，需要在服务器上的浏览器里另外登录。
- 建议给 AI 单独建一个浏览器用户资料，只在那里登录要给它用的网站。
- 「管理」里能看到连着的电脑、AI 在电脑上能用的标签页，并可以「断开」；在扩展里点「断开配对」也一样。

## 素材库

素材库是同一作品库里所有作品共用的素材（例如“品牌”“音效”“通用背景”），可以有多个。每个素材库是作品库里一个独立的分支（`materials/<id>`），版本和 GitHub 同步各管各的。id 在新建时由名称得到，之后不再改变：作品按 id 引用素材库，素材地址也是 `materials/<id>/<文件>`；选项卡里素材库的「⋯」→「重命名」只改显示的名称，作品不受影响。

- 「素材」侧栏 →「素材库」：只列出本作品引用的素材库和其中的文件；在素材库标题上点上传按钮添加文件。作品自己的素材右键「存入素材库」，在弹窗里选一个素材库（或新建）分享给其他作品。
- **管理（选项卡）**：点「管理…」打开「素材库」选项卡：搜索素材库的名称和介绍，或所有素材库里的文件（路径和类型，例如“logo”“字体”）；排序和筛选与经验库的一样，适合本作品的写明理由；「引用」「不再引用」；展开一个素材库看它的文件（单击预览、拖到时间轴）；新建、上传、改名、删除。删除的素材库先进回收站（分支改名为 `materials-trash/<名称>`），可以恢复，首页的「回收站」也能看到；在回收站里时，已经锁定其中文件的作品照常使用锁定的版本。彻底删除会连同全部版本一起删除，所以还有作品引用它时不能彻底删除。
- 作品直接使用素材库里的文件（地址 `materials/<素材库>/<文件>`），不用复制：拖到时间轴，或右键添加到播放头处。还没引用的素材库里的文件（在「素材库」选项卡里）也可以直接拖进来，作品会自动引用那个素材库。「资源」选项卡默认只列本作品引用的素材库里的资源，切到「全部素材库」看所有的。AI 也可以按你的要求关联或取消关联素材库、新建素材库、往素材库里放文件和修改文件。
- **代码**：素材库里也可以放多个作品共用的代码（特效、转场、组件、着色器），作品用 `import … from "@materials/<素材库>/<路径>"` 直接导入，和素材一样按文件锁定版本（连同它导入的文件和用到的素材）。一般让 AI 来写：“把这个粒子效果整理到素材库「特效」里，以后的作品都能用”。右键代码文件可以「复制导入语句」。
- **预览**：和作品素材一样，单击素材库里的文件在编辑区的新选项卡里打开，显示尺寸、时长和本作品是否已锁定它；素材库里的文件被修改后预览会立即更新。素材库有新版本而本作品锁定的是旧版本时，可以在「最新版本」和「本作品的版本」之间切换对比，满意后点「更新到最新版本」。聊天里引用的素材也可以点击查看。
- **版本锁定**：作品用到的每个素材文件都锁定在当时的版本（放到时间轴时，或保存版本时，记录在作品的 `materials.lock.json`）。之后素材库里的文件再改，作品不受影响；素材库里有新版本时，素材卡片上会提示，可以单个或「全部更新」。
- 素材库的每次修改（上传、替换、移动、删除）都会保存为这个素材库的一个版本，在「版本与同步」→「素材库」下选中它，查看历史、恢复、和 GitHub 同步。删除素材库里的文件后，已经用到它的作品仍能使用锁定的版本。

## 版本与 GitHub

活动栏的「版本与同步」（经验库下面）和 VS Code 的源代码管理一样：上方列出作品、经验库、素材库和复盘资料（有复盘数据后才出现）。经验库和素材库下面列出本作品关联、引用的每一个库（作品库里的其他库不列出；点「经验库」「素材库」折叠或展开），每个库是一个独立的分支，单独保存、恢复和同步，互不影响。每一项都显示未保存的修改、未推送或 GitHub 上更新的版本、是否同步；选中一项，下方显示它的操作和版本：

- **保存版本**（作品和经验库；素材库和复盘资料每次修改都自动保存）、**同步**（先拉取 GitHub 上更新的版本，再推送本机的版本）、**拉取**、**刷新**（重新读取，并和 GitHub 比较）。作品库还没连接 GitHub 时是「发布到 GitHub」。
- **未保存的修改**：单击文件在编辑区打开改动选项卡（新旧行号对照，绿色为新增、红色为删除）；可以单个或全部放弃。
- **历史**：单击一个版本展开它改动的文件，单击文件打开这个版本对它的改动；右键版本「查看这个版本的全部改动」或「恢复到这个版本」（恢复会生成新版本，不会丢失历史）。

状态栏的分支名也打开这里。未保存修改的改动会随文件变化实时更新，「打开文件」跳到对应文件。长行默认自动换行（右上角「自动换行」可以关掉，改为左右滚动）；一行里只改了几个字时，改动的文字会额外加深标出。

作品库可以连接 GitHub：首页「连接 GitHub 作品库」添加已有仓库或新建仓库，或把本地作品库发布到 GitHub。每个作品是独立分支，推送/拉取互不影响。GitHub 账号在 设置 → GitHub 中用个人访问令牌添加。

**迁移作品**：本地作品库里的作品可以迁移到另一个作品库（例如连接了 GitHub 的库）。在首页作品卡片菜单选「迁移到作品库…」，或选中多个作品后点「迁移到…」，或在本地作品库的菜单选「迁移全部作品到…」；打开的作品也可以在「版本与同步」里迁移。迁移前会列出：一起迁过去的内容（全部版本和媒体文件、复盘资料、导出的视频、AI 对话），未保存的修改会先保存为一个版本；作品用到而目标库没有的素材库、经验库会复制过去，目标库已有同名的库时改用它，用到的素材文件在目标库里版本不同或没有时会提前提示。迁移后作品 id 不变，原来的库里不再保留，迁到连接 GitHub 的库后自动推送。AI 正在这个作品里工作、作品正在导出，或目标库已有同 id 的作品时不能迁移。

连接了 GitHub 的作品库自动同步，避免在旧版本上继续编辑：

- **自动推送**：保存版本（以及发布、恢复、合并、新建作品）后几秒内自动推送到 GitHub，经验库、素材库和复盘资料的修改也一样。离线时保存的版本，在服务启动后和每半小时会补推。状态栏显示「已同步到 GitHub」「正在推送」或「同步失败」。
- **GitHub 上有更新**：打开作品时、在版本选项卡点刷新时，以及推送时，FRAME 会和 GitHub 对比（不会定时检查）。GitHub 上有更新的版本（比如在另一台电脑上改过）时：
  - 本机没有冲突的修改：自动更新到最新版本，并提示「已从 GitHub 更新到最新版本」。
  - 本机有未保存的修改改了同样的文件，或 AI 正在工作：编辑区上方出现黄色提示「GitHub 上有更新的版本……本机的作品是旧的」，点「保存并合并」或「更新到最新版本」。
- **冲突**：本机和 GitHub 上都有新的版本时，编辑区上方出现红色提示，可以「合并双方」；双方改了同一处、无法自动合并时，选择「采用 GitHub 的版本」（本机的版本另存为备份）或「保留本机的版本」（GitHub 上的修改留在历史中）。处理之前不要继续编辑。
- 首页卡片上的「GitHub 有更新」「冲突」「未同步」标出各作品的状态；AI 也会被告知，作品是旧版本或有冲突时它不会修改作品，会请你先处理。

## 导出

「导出」选项卡（标题栏右上角的「导出」）：选择分辨率、帧率、范围和是否烧录字幕，然后选一种导出。也可以下载当前帧 PNG 和字幕 SRT。

- **导出 MP4（服务器）**：在服务器上用点击时的作品快照导出 H.264 + AAC 的 MP4，导出期间可继续修改。导出的文件列在「已导出」里，可以播放、下载、删除。没有显卡的服务器导出三维（WebGL）作品较慢。
- **在浏览器中导出 WebM（本机）**：用这台电脑的显卡渲染，编码为 VP9 + Opus 的 WebM，完全在浏览器里进行，不经过服务器，完成后自动下载。需要较新的 Chrome、Edge 或 Firefox，并且用 https 或 localhost 地址打开 FRAME。
  - **后台导出**：可以关掉导出选项卡、切换侧栏和作品、回到首页，也可以继续修改作品（不影响正在导出的内容）；浏览器切到别的标签页也照常导出。一次导出一个，后开始的排队。
  - **左下角的进度**：工作台状态栏的最左边（首页等页面是左下角的小按钮）显示百分比、进度条和剩余时间；点开列出所有导出（本机的和服务器的），有帧数、速度、预计剩余时间和完成时刻，可以暂停、继续、取消，完成的可以再次下载。
  - **中断后继续**：导出每 4 秒一段保存在浏览器里。关闭或刷新页面、浏览器崩溃后，再打开 FRAME 会从中断处接着导出，最多重做正在导出的那一段；另一个标签页里开着 FRAME 时，它会马上接过来。作品在中断期间改过时会先问：「继续」用现在的作品导出剩下的部分，「重新导出」从头开始。连续两次没导出一段就中断时不再自动继续，点「继续」重试。
  - 完成的视频在浏览器里保留 7 天，可以在列表里再次下载或移除。

## 发布

作品完成后点标题栏的「发布」（或首页作品卡片菜单「发布」）：当前所有修改保存为一个版本，作品变为只能查看。已发布的作品可以预览、查看文件和历史、导出、同步到 GitHub，但不能修改（编辑器、时间轴、属性、素材和音频都不能改，作品文件在磁盘上也是只读的）。AI 聊天照常可用：可以和 AI 复盘这个作品，让它整理经验库和素材库（写入、修改、保存经验库版本，往素材库里放、移动、删除文件，也可以新建经验库或素材库），只是它不会修改作品，也不会改变作品关联的库。要修改，点「取消发布」，或者「创建副本」接着做。发布状态记在 `project.ts` 的 `publishedAt` 中，随版本同步到其他设备。

**作品状态**：除了「编辑中」和「已发布」，还可以把作品标为「草稿」（还在构思）或「废案」（不再做了）。在首页作品卡片菜单选「标为草稿 / 标为编辑中 / 标为废案」，选中多个作品后点底部的「标为…」可以一起修改（已发布的会跳过）；在工作台的「属性 → 作品 → 状态」里也能改。改状态会立刻单独保存为一个版本，名为「标为草稿」等，并同步到 GitHub；其他还没保存的修改不受影响。首页卡片上会显示「草稿」「废案」，废案的封面变灰；作品列表上方可以按「草稿」「编辑中」「已发布」「废案」筛选（有这个状态的作品时才显示对应筛选）。发布会结束草稿或废案状态，取消发布后作品回到编辑中；创建的副本也是编辑中。状态记在 `project.ts` 的 `status` 中（`"draft"` 草稿、`"abandoned"` 废案，不写就是编辑中）。AI 能看到作品的状态，但不会修改它。

## 复盘

作品发到平台以后，在「复盘」选项卡（标题栏右上角的「复盘」）里记录它的表现（已发布的作品也可以记录）。复盘资料放在作品库的 `frame/reviews` 分支，每个作品一个文件夹，随 GitHub 同步；每次修改都自动保存为一个版本，在「版本与同步」→「复盘资料」里查看和恢复。

- **上传后台数据**：把平台后台导出的文件拖进「复盘」选项卡（或点「上传后台数据」），原样保存在 `raw/<当天日期>/`。抖音创作者中心的作品数据导出（指标数据、留存分析、播放量和涨粉量的每小时趋势、流量来源、涨粉脱粉与不感兴趣、观众参与度）和全部评论导出会被认出来，确认后直接导入成一次数据：数字、逐秒留存和同类作品的留存、每小时播放和涨粉、流量来源、评论最多赞的几条。第一次导入时自动建好发布记录（发布时间取每小时数据的第一个小时，标题取评论导出里的视频标题）。文件夹旁的「导入」可以重新导入。其他平台的表格和截图标着「未录入」，在文件的菜单里选「让 AI 录入这个文件」。表格单击在编辑区以表格打开（多个工作表可以切换），截图直接显示。
- **发布记录**：平台、发布时间、链接、发布时的标题和话题、置顶评论、账号、目标（例如播放 100 万），以及发布的是哪个导出文件（记下当时的作品版本和视频时长）。同一个作品发到几个平台，或换了封面重发，各记一条。
- **录入数据**：「录入数据」手动填写某个时间点的累计数字（可以写 `1.2万`；比例填百分数）、平台特有的指标（例如 B 站的投币）、观众留存曲线和同类作品的留存曲线（每行“视频第几秒 还在看的百分比”）。「发布后 1 / 2 / 3 / 7 / 14 / 30 天」按钮直接填好统计时间。
- **看数据**：
  - 卡片：最新的数字和比例，旁边是同类作品的值和目标完成多少（某个数字来自更早的一次记录时会注明第几天）。
  - 每小时播放：柱状图，下面是首 24 / 48 / 72 小时的播放和流量来的几波。
  - 累计增长：数字随发布时间的变化。
  - 观众留存：这个作品和同类作品的曲线画在作品自己的时间上，标出关键时刻（例如反转）。
  - 流失率 ÷ 同类：每一秒走掉的比例是同类作品的几倍，列出最高的几秒和当时的图层、歌词、镜头。
  - 分段：按图层（幕）、歌词、镜头、字幕或自己划的段落，每段的倍数和“这一段按同类的流失率走，看到结尾的人多多少”。
  - 流量来源：和账号近 7 天的平均对比。
  - 评论：赞最多的几条。

  点曲线或条目，预览跳到那一刻。
- **复盘文档**：复盘的结论写在 Markdown 文档里，在编辑区打开、编辑，保存即是一个版本。
- **让 AI 复盘**：AI 导入或录入数据（口径拿不准时会先问你），和同类作品在同一发布天数比较，看流失高的几秒和段落的画面找原因，写进复盘文档，最后列出值得写进经验库的经验，经你同意后写入。

**复盘对比**：首页的「复盘对比」（或「复盘」选项卡的对比按钮）把所有作品的发布记录放在一起：每条一行，都取发布后同一天数的数据（第 1、2、3、7、14、30 天，取那一天前后最接近的一次记录；有每小时数据时播放和涨粉正好算到那一天，标 *），因为总数会一直增长，不同天数的数字不能直接比。打开时停在大多数作品都到了的那一天。比例和留存旁边是同类作品的值，标了关键时刻的作品多一列“反转时还在”。可以按平台、标签、作品库筛选，点表头排序，最后一行是中位数。勾选最多 4 条放进图表：累计增长、按视频进度对齐的观众留存（还在看的比例，或是同类的几倍）、按日期对齐的每小时播放（账号整体的流量波动会同时出现）。

永久删除作品时，它的复盘资料也一起删除（分支历史里仍然保留）。

## 回收站与本地空间

- **AI 请求删除**：AI 不能删除作品。你让它删除时，它只把作品标记为「AI 请求删除」（附上原因）；首页上方会列出这些作品，点「确认删除」移到回收站，或点「保留」取消标记。卡片上也有「AI 请求删除」标记，菜单里可以保留。
- **移到回收站**：首页作品卡片菜单。作品分支 `works/<id>` 改名为 `trash/<id>`，本机和 GitHub 上一起改，其他设备同步后也会在回收站里看到它。
- **回收站**：首页作品库标题旁的「回收站」。「恢复」把分支改回原名；「永久删除」删除本机和 GitHub 上的分支，以及这个作品导出的视频、复盘资料和 AI 对话，无法恢复；「清空回收站」永久删除全部。删除的素材库和经验库也在这里（它们放在各自分支的回收站里），可以恢复或永久删除（之后只能从版本历史里找回）。
- **释放本地空间**：已同步到 GitHub 的作品，卡片菜单「释放本地空间」删除本机上的副本（包括只有它用到的素材文件），只保留 GitHub 上的；之后打开时会重新下载。还有未保存或未同步的修改时不能释放。卡片上的「未同步」「仅本机」「仅 GitHub」标出作品在哪里。

## 触屏

平板和手机上同样可以使用：

- **长按**等于右键：文件、素材、库、版本、时间轴片段和音轨上长按打开菜单（添加到播放头处、引用到 AI 聊天、删除等）。
- **时间轴**：单指滑动滚动；双指捏合缩放；点一下空白处定位播放头，在刻度尺上拖动可以连续定位。先点一下片段选中它，再拖动它移动、拖两端裁剪（没选中的片段上滑动只会滚动时间轴，不会误移动）。
- 素材不能用手指拖到时间轴：长按它选「添加到画面」或「放到音轨」，放在播放头处。
- 界面和电脑上一样（按钮、文字大小不变）；分隔条、播放头和片段两端的手柄可以用手指拖动；点输入框时 iOS 不会自动放大页面。窄屏上侧边栏和 AI 聊天从边缘滑出，盖在编辑区上方，点空白处收起。
