# FRAME 作品管理与 AI 创作平台

产品中心是作品。首页展示封面、名称、分类、制作状态和更新时间；打开作品进入同一创作页，在画面旁对话，查看素材、配音、版本与导出。关闭浏览器不取消服务器上的任务。

平台代码仓库为 `jianjianai/frame-studio`；现有作品已迁入独立的私有作品仓库 `jianjianai/frame-works`。作品仓库不是平台仓库的子模块，也不包含平台代码。平台仓库的 `/projects/` 仅供临时测试工作区使用，被 Git 和 Docker 忽略。容器执行任务时把单个作品放进隔离运行目录，由镜像提供引擎和依赖。

## 内容与运行时

每个作品有稳定的 UUID，对应内容仓库中的 `projects/<slug>/`。仓库只存作品内容及关联素材，共享引擎、依赖和制作工具由平台镜像提供。新作品自动使用默认内容库，不需要先创建或选择开发工程。GitHub 是设置中的同步目标，可配置多个仓库，每个仓库存放多个作品。

作品资料保存在 `production/work.json` 并索引到数据库。作品回收站保留源码和素材，可以恢复。版本快照保存在服务器数据目录。素材使用到作品时复制进入该作品 `public/` 并记录来源，随内容仓库一起同步。未引用表示没有任何作品素材文件使用该素材内容；包括回收站中的作品，以避免误删。

预览只运行当前作品的播放器组件（画面、播放控制、时间轴），不加载旧工作台的首页、导航或素材管理页面。作品代码在隔离的预览文档和独立任务容器中运行。

## 统一操作

网页、MCP 与 CLI 使用同一组 `works_*` 操作：列出、创建、打开、编辑资料和源码、复制、回收恢复、素材、配音、预览、导出、版本与 AI 对话。外部 AI 以作品 UUID 操作，无需拼接仓库和工程路径。

容器内 AI 使用本地 `film` 工具编辑/审片；`work-tool.mjs` 提供任务范围内的素材搜索、素材导入和语音合成。任务凭证只能用于当前运行任务，结束后失效。原始管理凭证不会传给 AI。

具备浏览器能力的 AI 调用 `works_browser` 获得专用审片页，以 `FRAME_AI` 控制台 API 查看帧、播放片段、截图和导出。服务器只进行源码编译，渲染、音频与编码在 AI 的浏览器执行。接口与限制见 [AI-BROWSER](AI-BROWSER.md)。

## 页面

- 作品库：搜索、分类、制作状态、回收站、新建、复制、打开。
- 作品创作页：画面和时间轴、AI 对话、素材、配音、导出、版本、作品资料；源码编辑放在辅助入口。
- 素材库：上传、预览、标签、作品引用、未引用筛选、回收站。
- 设置：AI 工具与密钥、语音引擎/模型及测试、GitHub 内容仓库、MCP 令牌、登录密码。

验收以“新建作品 → 对话/编辑 → 预览 → 配音与素材 → 导出 → 同步”为主线，另验证刷新重开、任务续接和移动端。
