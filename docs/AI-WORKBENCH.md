# FRAME AI 视频工作台

FRAME 使用完整官方 Paseo WebUI 和 daemon 进行 AI 创作，原生流式回答、工具、权限、文件编辑、终端和 Git 工作树由 Paseo 负责，接入与边界见 [Paseo 创作工作区](PASEO.md)。旧 FRAME 对话、执行事件和结果继续只读保留。

产品以 AI 创作和人类审片为中心。作品页以播放器、时间轴和可收起的工作面板为核心；AI、素材、配音、任务和同步共用工作面板，版本、导出与资料使用弹窗。工具布局见 [作品工具与工作面板](WORKSPACE-TOOLS.md)。保留现有配色。人工不需要接触源码、工程 id、渲染器或依赖。

## 信息架构

- 首页是最近打开的作品，按访问时间分页；仓库页按账号、名称分页检索。仓库 → 作品列表 → 创作页。作品卡片菜单只有重命名、删除，删除要求输入完整作品名并进入可恢复回收站。
- 新建作品必须属于选定仓库，只需名称。默认可播放的空白作品由平台生成；叙事、技术、时长、画幅由 AI 根据指令制作。
- 后台项目按作品聚合运行状态，点击返回创作页，可停止该作品正在执行/排队的工作。工具升级留在设置中。
- 作品从列表在独立新标签页打开。作品页只显示当前作品内容，不显示全局导航；播放器与 AI 固定左右分栏，不再提供上下切换。AI 对话可关闭和重新打开，关闭不丢草稿、不停止任务。窄屏 AI 使用可收起侧层，不在播放器下方堆积长页面。分割线仅 1 CSS 像素，悬浮、键盘聚焦或拖动时才显示，透明命中区支持鼠标和触摸。

## 同步边界

一个 GitHub 仓库中，每个作品独占 `works/<不可变作品 id>` 分支。服务端使用各自 Git worktree，因此历史、未提交修改、领先/落后、拉取/推送互相独立。显示名更改不改变分支。新作品使用独立根提交，不继承其他作品历史；迁移旧布局时保留原默认分支作为恢复依据。作品页显示当前作品分支及最后远端检查时间；离线保留已知状态并显示错误。

仓库素材库放在专门的 `frame/materials` 分支，使用到作品的文件复制进作品分支，保证独立重放与导出。作品推送只提交该作品及其关联素材，然后普通 push；拒绝强推。拉取仅允许当前分支干净且可 fast-forward。活跃任务只阻止同作品修改和同步，不阻塞同仓其他作品。仓库页可发现新远端作品分支，素材库独立同步。

## 播放器

画面与音频共用播放器的绝对时间。V8 实时预览直接运行场景与代码音频，支持原始素材、压缩素材及全部缓存三种资源模式，独立于画质选择。原始模式不对素材转码；压缩模式复用服务器按需生成的媒体代理；缓存模式在浏览器校验并保存播放所需素材、模块与运行资源，显示进度、待下载文件、取消和重试，更新后自动下载新版本。

缓存完成后按已校验资源播放；CPU、解码和场景初始化仍可能需要准备时间。缓存完成而播放器初始化失败时，明确显示素材已缓存与准备失败，并可重试准备。正式导出使用原始媒体。模式、更新与缓存边界见 [V8 实时预览](V8-LIVE-PREVIEW.md)，音频编辑与完整 Tone / Signalsmith 接口见 [音频创作](AUDIO-CREATIVE.md)。

作品加载从下载播放器、准备画面开始显示阶段和进度条，无法预知总量时显示不定进度，不编造百分比。宽屏左侧工具条提供 AI、素材、配音、任务、同步与导出；作品菜单包含版本和资料，窄屏使用单行顶部工具栏。作品名称与更新预览复用播放器信息行。播放器始终显示独立可拖动进度条和画质选项。时间轴可隐藏/显示，视频与时间轴占比可拖动并记忆，不影响独立进度条。后台任务面板显示实际可计量的音频生成进度、状态、错误与停止按钮；AI 无法预计总工作量时显示阶段。同步按钮高亮显示本地领先、远端领先和未提交文件数；进入作品和返回页面时有节制地刷新远端，失败保留已知状态并可查看检查时间。

网页动作与订阅通过 `/api/ws`，PostgreSQL LISTEN/NOTIFY 驱动更新，移除 `/api/action` 定时轮询。断线重连重新订阅并从持久事件游标恢复；写动作不自动重放，避免重复执行。`/api/action` 保留给 CLI 和兼容客户端。WebSocket 升级要求同源及有效登录，消息、心跳和订阅更新再次校验会话。

## AI 执行

提供商与创作工具分离：FRAME 连接持有 Codex / Claude 的认证及启用模型，Paseo 原生选择器显示对应 profile。官方登录使用工具自身流程；API 凭据加密保存，只在所选原生 session 启动时提供。名称、模型与启用状态通过官方配置 RPC 同步，保留原生自定义 profile 和当前回合。

发送前冻结原始画面、素材、提供商和模型选择，并绑定原生消息 UUID。原生 Paseo 回执决定消息是否已经发送：已完成回执的重试不会重复执行；结果不明保留状态并明确提示。未发送的冻结消息若模型改变，必须恢复原选择或明确创建新消息。

主工作区的文件编辑、终端和 AI 修改进入同一草稿观察通道。候选快照经过范围、结构、测试、类型、实际画面和短音频验证，再复用 FRAME 的原子应用、版本和撤销。官方 Git 工作树独立预览，合并回主工作区后才进入正式作品的验证应用。

## AI 对话与设置

提供商与模型设置支持发现、筛选、批量导入、带来源的规格、手动覆盖与删除。同步保留自定义名称、启停状态及覆盖值；未知参数不猜测，详情见 [提供商与模型配置](PROVIDER-MODELS.md)。

创作区直接嵌入官方 Paseo 页面。对话、模型、输入、附件、权限、运行中 steer / interrupt、历史搜索和原生设置采用其实际界面与执行语义。FRAME 提供当前画面和素材引用、预览入口、结果及旧历史摘要；不会把旧 FRAME 排队发送协议套在原生消息上。关闭工作面板保留已挂载的原生会话，后台执行继续，窄屏可以展开后返回播放器。

设置分为 AI 模型、GitHub、语音引擎、创作工具、访问设置、运行状态；支持分类搜索和 `#/settings/<分类>` 深链接。提供商页采用列表与详情布局，支持编辑连接、测试、启用/停用，保留历史对话；模型支持手动添加、发现后选择性添加、设置默认、启用/停用和移出目录。

API 模型发现调用保存地址的模型目录接口，响应有时间、字节数和数量上限，不跟随携带凭据的重定向，不回传原始错误或密钥。发现结果不等于验证通过。API 测试会发送少量模型请求，可能产生费用；官方登录检查只确认 CLI 登录状态，不承诺任意模型可用。Codex 官方账号登录成功后自动读取原生工具目录及能力参数，设置页可同步、查看来源并重试；模型目录可能缓存，不承诺账号推理权限。Claude 官方账号可手动填写支持的模型 ID 或使用工具默认模型。

设置页从不取回已保存 API 密钥，留空保留旧值；显示密钥按钮仅作用于本次输入。配置保存使用版本检查，过期表单不能覆盖并发修改。最近测试记录包含模型、时间、延迟和结果，慢测试不会覆盖新的地址或密钥。FRAME 设置与后台状态通过平台 WebSocket 更新，原生 profile 通过 Paseo 官方配置 RPC 刷新。

原生 Paseo 负责持久化会话、消息投递回执、timeline 与断线恢复。FRAME 独立保存冻结引用、草稿版本和验证候选，保留旧 PostgreSQL 对话、任务、事件以及只读历史入口。验证失败或取消保留草稿和错误，不将失败结果覆盖正式作品；应用失败可重试保存，不重新调用 AI。

## 存储与规模

作品和素材按仓库索引；页面使用有上限的分页查询，不因打开首页扫描全部仓库。仓库同步/作品变更后更新对应索引。引用关系删除前再校验。素材原件按内容散列去重，仓库内保留可同步的素材文件和元数据，使用到作品时复制到作品自身资源目录。

导出归临时产物，不自动注册素材。保留截止时间、下载、主动删除、后台到期清理；正在下载/上传 Releases 的文件要保护。发布到对应作品仓库的 GitHub Releases，完成后记录链接。保留最近有效预览，清理过时构建、失效能力链接、过期上传与无效任务凭证。

登录密码仅由 FRAME_ADMIN_PASSWORD 管理；应用每次启动验证配置，变更密码后撤销旧会话。网页与 MCP 均没有修改密码入口。

## 验收

逐项记录实现和真实验证，不能以构建通过代替产品验收。重点覆盖慢网首播、冷跳转、拖动取消、音画漂移、轨道混音、断线续接、后台停止、跨作品并发、同仓同步隔离、多账号重登、临时文件清理、分页规模和键盘/窄屏交互。外部账号授权须由用户完成，只有真实登录与模型执行成功才能记录对应验收通过。

官方接入依据：[Codex 登录](https://learn.chatgpt.com/docs/auth)、[Codex 提供商配置](https://learn.chatgpt.com/docs/config-file/config-advanced)、[Claude CLI](https://code.claude.com/docs/en/cli-reference)、[GitHub CLI 登录](https://cli.github.com/manual/gh_auth_login)。

## 审片与交付交互

对话明确使用时间或选段引用，不把时间码称为截图。引用在发送后保留，点击可定位画面；素材引用可逐项移除，不删除资源。消息以安全富文本显示基础 Markdown 和可定位时间，原始 HTML 始终作为文字处理；不同对话独立保留草稿。

版本支持文件差异和独立历史预览，历史构建从同一作品分支可达的 Git 提交提取普通文件，只写任务隔离目录，不切换当前 HEAD，不自动恢复。历史预览与当前有效预览分开选择和保留。早期本地快照明确标识，无伪造的可视比较。

导出集中选择格式/执行位置、分辨率、帧率、全片或选段、字幕。后台 MP4 使用任务开始时的作品源码，本机 WebM 使用当前已加载预览，两者统一使用作品原始音轨设置。WebM 状态保留在作品页，关闭导出弹窗不中断；关闭或刷新标签页会中断并提示。后台状态分别显示排队、执行、停止中、已停止、失败、完成，文件显示实际保留期限。本机下载文件不受服务器清理。

素材分为本作品资源、仓库素材库和回收站。引用到对话、复制为作品资源和编排到时间轴是不同动作。配音先生成临时试听，采用时保存原试听字节，不重复合成；可以把位置和采用资源带入对话草稿，用户确认后再发送。

弹窗使用原生顶层对话框，通知进入当前顶层弹窗，保存错误同时显示在表单内。编辑表单关闭时提示未保存输入，提交期间防重复且阻止误关闭。首页作品卡片展示制作状态与任务状态，搜索无匹配、空仓库、加载和错误分别处理。
