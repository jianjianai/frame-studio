# FRAME AI 视频工作台

FRAME 使用完整官方 Paseo WebUI 和 daemon 进行 AI 创作，原生流式回答、工具、权限、文件编辑、终端和 Git 操作由 Paseo 负责，接入与边界见 [Paseo 创作工作区](PASEO.md)。旧 FRAME AI 执行器、聊天界面、聊天记录和专用持久数据全部移除。作品工作区与后台导出遵循本文“单一作品工作区与导出隔离”。

产品以 AI 创作和人类审片为中心。作品页以播放器、时间轴和可收起的工作面板为核心；AI、素材、配音、任务和同步共用工作面板，版本、导出与资料使用弹窗。工具布局见 [作品工具与工作面板](WORKSPACE-TOOLS.md)。保留现有配色。人工不需要接触源码、工程 id、渲染器或依赖。

## 信息架构

- 首页是最近打开的作品，按访问时间分页；仓库页按账号、名称分页检索。仓库 → 作品列表 → 创作页。作品卡片菜单只有重命名、删除，删除要求输入完整作品名并进入可恢复回收站。
- 新建作品必须属于选定仓库，只需名称。默认可播放的空白作品由平台生成；叙事、技术、时长、画幅由 AI 根据指令制作。
- 后台项目按作品聚合运行状态，点击返回创作页，可停止该作品正在执行/排队的工作。工具升级留在设置中。
- 作品从列表在独立新标签页打开。作品页只显示当前作品内容，不显示全局导航；播放器与 AI 固定左右分栏，不再提供上下切换。AI 对话可关闭和重新打开，关闭不丢草稿、不停止任务。窄屏 AI 使用可收起侧层，不在播放器下方堆积长页面。分割线仅 1 CSS 像素，悬浮、键盘聚焦或拖动时才显示，透明命中区支持鼠标和触摸。

## 单一作品工作区与导出隔离

**需求状态：单一工作区改造已实现，8.3.2 发布验收进行中。** 实际检查和生产切换结果见 [维护记录](../records/2026-10-03-ai-workbench-8.3.2.md)。

### 唯一创作工作区

- 每个作品只有一个权威、持久、可编辑的工作区。打开作品时只启动该作品的一个创作运行环境；重复打开、刷新、重新连接或切换工具复用已有工作区和 Paseo daemon，不再复制作品创建另一套创作环境。
- FRAME 可视编辑器、Paseo 文件编辑器与终端、AI、CLI、平台及本地 MCP、素材编排和实时预览全部解析到同一作品目录，使用同一套源码、素材和版本标识。不得保留“正式作品”和“AI 草稿”两份可分别修改的权威源码，再靠验证应用来同步。
- 同一作品可以有多个对话或 Agent，但全部共享该工作区。不得按对话、Agent、MCP 调用或预览另建工作树、持久草稿或长期容器；Paseo 的工作树创建不作为 FRAME 作品内的创作入口。并发修改继续使用版本检查和必要的短时写入锁，冲突明确反馈。
- 实时预览直接监听该工作区的已保存变化，并明确报告实际显示的 revision。日常创作无需在“作品预览”“Paseo 主工作区预览”和“对话工作树预览”之间选择。预览所需的编译产物、媒体代理和缓存不形成另一份可编辑源码目录。
- 日常结构检查、类型检查和项目测试复用该工作区；不因一次保存或 AI 回合结束复制完整项目、启动另一套创作工作区。验证报告绑定被检查的 revision，过时报告不能代表当前源码。验证失败保留用户修改及错误，播放器可保留最后成功画面；不得从另一份目录自动覆盖当前工作区。Git 版本、同步和撤销均围绕唯一工作区进行。
- 关闭工作面板不丢失对话、已保存源码或后台任务。历史版本及消息引用保留为明确标识版本的只读记录，不成为新的创作工作区或默认导出来源。已有草稿、工作树和未提交修改在后续迁移时必须先核对并保留，不能自动覆盖或删除。

### 后台导出的临时冻结副本

- 后台长时间导出被接受时，冻结唯一工作区的已保存源码、原始素材、运行时版本和导出参数，记录准确 revision。未保存的表单输入须明确提示；不能悄悄改用另一份“正式作品”目录，也不能在排队后才重新取用更新过的源码。
- 导出按需创建只服务于本次任务的临时冻结副本和执行进程或容器，不创建额外 AI 对话、Agent 或长期创作工作区。公共引擎、依赖及工具按固定版本只读复用。
- 快照准备完成后释放对当前工作区的准备锁。排队和编码期间可继续编辑、预览及运行 AI/MCP；后续修改不改变已冻结导出的输入，导出也不能覆盖或回写当前工作区。
- 成功时先独立保存并确认成片可下载，再立即销毁临时源码副本、混音及编码临时文件和执行环境。失败、取消和超时同样释放本次临时文件及进程或容器；异常退出留下的资源由恢复机制核对任务身份后清理，不留下休眠容器或长期执行目录。
- 成片、任务状态、版本标识、参数和必要诊断记录单独保留，沿用下载、到期清理和 Releases 上传保护规则；保留成片不要求保留整份临时工作区。若提供重试或恢复，必须基于记录的确切版本重新准备临时副本，不自动换成当前新版本。
- 本机 WebM 沿用锁定实际已显示版本的编码方式，明确其 revision；无须为本机编码启动额外服务器创作工作区。后台 MP4 与本机 WebM 均使用对应冻结版本的原始媒体和作品音轨设置。

### 验收要求

1. 同一作品在多个标签页和多个对话中打开，只复用一个创作工作区及运行环境；关闭、刷新和重连不生成持久副本。
2. 可视编辑、Paseo 编辑、AI、CLI 和 MCP 修改同一份文件，其他入口与实时预览能读到相同 revision，无需应用到另一目录或切换预览来源。
3. 导出版本 A 后立即继续编辑成版本 B，编码期间创作正常，输出仍准确来自 A；导出排队期间的更新也不能改变输入。
4. 导出成功、失败、取消、超时及异常恢复后，本次临时副本和执行环境均释放；成功成片仍可下载，任务记录和版本信息仍可查询，其他作品及其资源不受影响。

## 同步边界

一个 GitHub 仓库中，每个作品独占 `works/<不可变作品 id>` 分支。服务端使用各自 Git worktree，因此历史、未提交修改、领先/落后、拉取/推送互相独立。显示名更改不改变分支。新作品使用独立根提交，不继承其他作品历史；迁移旧布局时保留原默认分支作为恢复依据。作品页显示当前作品分支及最后远端检查时间；离线保留已知状态并显示错误。

仓库素材库放在专门的 `frame/materials` 分支，使用到作品的文件复制进作品分支，保证独立重放与导出。作品推送只提交该作品及其关联素材，然后普通 push；拒绝强推。拉取仅允许当前分支干净且可 fast-forward。按单一工作区目标，会修改当前源码的操作只协调同作品的必要写入和同步，不阻塞同仓其他作品；已冻结的后台导出不在整个编码期间阻止当前作品继续创作。仓库页可发现新远端作品分支，素材库独立同步。

## 播放器

画面与音频共用播放器的绝对时间。V8 实时预览直接运行场景与代码音频，支持原始素材、压缩素材及全部缓存三种资源模式，独立于画质选择。原始模式不对素材转码；压缩模式复用服务器按需生成的媒体代理；缓存模式在浏览器校验并保存播放所需素材、模块与运行资源，显示进度、待下载文件、取消和重试，更新后自动下载新版本。

缓存完成后按已校验资源播放；CPU、解码和场景初始化仍可能需要准备时间。缓存完成而播放器初始化失败时，明确显示素材已缓存与准备失败，并可重试准备。正式导出使用原始媒体。模式、更新与缓存边界见 [V8 实时预览](V8-LIVE-PREVIEW.md)，音频编辑与完整 Tone / Signalsmith 接口见 [音频创作](AUDIO-CREATIVE.md)。

作品加载从下载播放器、准备画面开始显示阶段和进度条，无法预知总量时显示不定进度，不编造百分比。宽屏左侧工具条提供 AI、素材、配音、任务、同步与导出；作品菜单包含版本和资料，窄屏使用单行顶部工具栏。作品名称与更新预览复用播放器信息行。播放器始终显示独立可拖动进度条和画质选项。时间轴可隐藏/显示，视频与时间轴占比可拖动并记忆，不影响独立进度条。后台任务面板显示实际可计量的音频生成进度、状态、错误与停止按钮；AI 无法预计总工作量时显示阶段。同步按钮高亮显示本地领先、远端领先和未提交文件数；进入作品和返回页面时有节制地刷新远端，失败保留已知状态并可查看检查时间。

网页动作与订阅通过 `/api/ws`，PostgreSQL LISTEN/NOTIFY 驱动更新，移除 `/api/action` 定时轮询。断线重连重新订阅并从持久事件游标恢复；写动作不自动重放，避免重复执行。`/api/action` 保留给 CLI 和兼容客户端。WebSocket 升级要求有效登录，消息、心跳和订阅更新再次校验会话；入口来源与 TLS 策略沿用已有部署，不增加应用级域名检查或强制 TLS 配置。

## AI 执行

提供商与创作工具分离：FRAME 连接持有 Codex / Claude 的认证及启用模型，Paseo 原生选择器显示对应 profile。官方登录使用工具自身流程；API 凭据加密保存，只在所选原生 session 启动时提供。名称、模型与启用状态通过官方配置 RPC 同步，保留原生自定义 profile 和当前回合。

发送前冻结原始画面、素材、提供商和模型选择，并绑定原生消息 UUID。原生 Paseo 回执决定消息是否已经发送：已完成回执的重试不会重复执行；结果不明保留状态并明确提示。未发送的冻结消息若模型改变，必须恢复原选择或明确创建新消息。

目标流程中，可视编辑、文件编辑、终端、AI 和 MCP 修改进入唯一工作区的同一源码观察通道。范围、结构、测试、类型、实际画面和短音频验证绑定该工作区的 revision，FRAME 管理版本和撤销；不再把独立草稿候选应用到另一份正式作品目录，也不以合并额外创作工作树作为日常完成步骤。工作区及导出改造的状态和验收以“单一作品工作区与导出隔离”为准。

## AI 对话与设置

提供商与模型设置支持发现、筛选、批量导入、带来源的规格、手动覆盖与删除。同步保留自定义名称、启停状态及覆盖值；未知参数不猜测，详情见 [提供商与模型配置](PROVIDER-MODELS.md)。

创作区直接嵌入官方 Paseo 页面，并提供“在新标签页打开 Paseo”。独立标签页保留当前对话路由并复用同一 daemon、会话和工作区，发送直接使用已登录的作品 API。独立页面没有播放器定位时，不伪造时间、选段或素材引用；返回作品页后可以引用实际画面。对话、模型、输入、附件、权限、运行中 steer / interrupt、历史搜索和原生设置采用其实际界面与执行语义。FRAME 提供当前画面和素材引用、预览入口及对应版本验证结果。原生发送采用 Paseo 的消息 UUID 和投递回执。关闭工作面板保留已挂载的原生会话，后台执行继续，窄屏可以展开后返回播放器。

设置分为 AI 模型、GitHub、语音引擎、创作工具、访问设置、运行状态；支持分类搜索和 `#/settings/<分类>` 深链接。提供商页采用列表与详情布局，支持编辑连接、测试、启用/停用；模型支持手动添加、发现后选择性添加、设置默认、启用/停用和移出目录。

API 模型发现调用保存地址的模型目录接口，响应有时间、字节数和数量上限，不跟随携带凭据的重定向，不回传原始错误或密钥。发现结果不等于验证通过。API 测试会发送少量模型请求，可能产生费用；官方登录检查只确认 CLI 登录状态，不承诺任意模型可用。Codex 官方账号登录成功后自动读取原生工具目录及能力参数，设置页可同步、查看来源并重试；模型目录可能缓存，不承诺账号推理权限。Claude 官方账号可手动填写支持的模型 ID 或使用工具默认模型。

设置页从不取回已保存 API 密钥，留空保留旧值；显示密钥按钮仅作用于本次输入。配置保存使用版本检查，过期表单不能覆盖并发修改。最近测试记录包含模型、时间、延迟和结果，慢测试不会覆盖新的地址或密钥。FRAME 设置与后台状态通过平台 WebSocket 更新，原生 profile 通过 Paseo 官方配置 RPC 刷新。

原生 Paseo 负责持久化会话、消息投递回执、timeline 与断线恢复。FRAME 保存冻结引用、作品 revision、版本和对应验证报告。旧 FRAME 聊天、旧 AI 任务及附属事件、令牌、问答、通知和旧会话文件全部清理，不提供保留或恢复入口；当前原生 Paseo 会话和作品 Git 历史保留。验证失败或取消保留当前修改和错误；保存或版本记录失败可重试，不重新调用 AI。

## 存储与规模

作品和素材按仓库索引；页面使用有上限的分页查询，不因打开首页扫描全部仓库。仓库同步/作品变更后更新对应索引。引用关系删除前再校验。素材原件按内容散列去重，仓库内保留可同步的素材文件和元数据，使用到作品时复制到作品自身资源目录。

导出成片归临时产物，不自动注册素材。成片保留截止时间、下载、主动删除、后台到期清理；正在下载/上传 Releases 的文件要保护。发布到对应作品仓库的 GitHub Releases，完成后记录链接。按导出隔离目标，临时源码副本和执行环境在任务结束后立即释放，与成片保留期限分开管理。保留最近有效预览，清理过时构建、失效能力链接、过期上传与失效能力凭证。

登录密码仅由 FRAME_ADMIN_PASSWORD 管理；应用每次启动验证配置，变更密码后撤销旧会话。网页与 MCP 均没有修改密码入口。

## 验收

逐项记录实现和真实验证，不能以构建通过代替产品验收。重点覆盖慢网首播、冷跳转、拖动取消、音画漂移、轨道混音、断线续接、后台停止、跨作品并发、同仓同步隔离、多账号重登、临时文件清理、分页规模和键盘/窄屏交互。外部账号授权须由用户完成，只有真实登录与模型执行成功才能记录对应验收通过。

官方接入依据：[Codex 登录](https://learn.chatgpt.com/docs/auth)、[Codex 提供商配置](https://learn.chatgpt.com/docs/config-file/config-advanced)、[Claude CLI](https://code.claude.com/docs/en/cli-reference)、[GitHub CLI 登录](https://cli.github.com/manual/gh_auth_login)。

## 审片与交付交互

对话明确使用时间或选段引用，不把时间码称为截图。引用在发送后保留，点击可定位画面；素材引用可逐项移除，不删除资源。消息以安全富文本显示基础 Markdown 和可定位时间，原始 HTML 始终作为文字处理；不同对话独立保留草稿。

版本支持文件差异和独立历史预览，历史构建从同一作品分支可达的 Git 提交提取普通文件，只写任务隔离目录，不切换当前 HEAD，不自动恢复。历史预览与当前有效预览分开选择和保留。早期本地快照明确标识，无伪造的可视比较。

导出集中选择格式/执行位置、分辨率、帧率、全片或选段、字幕。按导出隔离目标，后台 MP4 使用任务被接受时冻结的唯一工作区版本，本机 WebM 使用当前已加载并锁定的预览版本，二者明确记录 revision 并使用该版本的原始音轨设置。WebM 状态保留在作品页，关闭导出弹窗不中断；关闭或刷新标签页会中断并提示。后台状态分别显示排队、执行、停止中、已停止、失败、完成，文件显示实际保留期限。本机下载文件不受服务器清理。

素材分为本作品资源、仓库素材库和回收站。引用到对话、复制为作品资源和编排到时间轴是不同动作。配音先生成临时试听，采用时保存原试听字节，不重复合成；可以把位置和采用资源带入对话草稿，用户确认后再发送。

弹窗使用原生顶层对话框，通知进入当前顶层弹窗，保存错误同时显示在表单内。编辑表单关闭时提示未保存输入，提交期间防重复且阻止误关闭。首页作品卡片展示制作状态与任务状态，搜索无匹配、空仓库、加载和错误分别处理。
