# Windows 控制中心

完整工作台在默认浏览器打开。Windows 控制中心是独立的原生窗口，负责运行状态、依赖准备与修复、重启、更新和日志。程序不嵌入工作台，也不依赖 WebView2。SQLite 与 Windows 原生任务复用公共服务层。安装向导和控制中心保持 FRAME 的浅色纸张、深绿文字和绿色强调色。

## 用户流程

安装向导说明安装位置、首次下载与缓存复用，提供桌面快捷方式选项。安装过程逐阶段显示当前工作、下载量、速度和进度；取消保留已下载内容，失败留在向导并可直接重试。依赖校验通过后才安装应用和切换入口。

启动显示准备状态，快速检查已安装环境，随后在默认浏览器打开工作台并收起到托盘；语音服务在后台准备，不阻塞作品、预览、导出和 AI。托盘左键打开浏览器，右键可以打开控制中心、运行环境、应用更新、重启、数据目录或退出。关闭控制中心会收起到托盘，浏览器与后台任务继续运行。重复启动打开已有服务的浏览器地址。开始菜单另提供“Windows 控制中心”快捷方式。启动失败提供重试、环境修复、日志与上一版本入口。

控制中心分为运行概览、运行环境、应用更新、日志与诊断四页。概览显示地址、任务数与语音状态；环境页提供依赖检查、修复、下载进度与暂停；更新页提供版本状态、检查、继续下载、重启更新和自动更新开关；日志页打开独立的数据目录及运行、安装和更新日志。

本地首页可直接创建作品并自动准备默认本地仓库，不要求先理解 GitHub 或服务器连接。AI 设置显示这台电脑上 Codex/Claude 的安装与登录状态，缺少 CLI 时提供安装说明，已安装时可以打开登录终端和重新检测。语音模型仍由用户在模型列表选择下载，也支持自定义模型。

## 自动更新

默认每日检查正式 GitHub Release；长时间运行的程序也会定期触发检查，在后台下载新版 Setup。仅接受本仓库发布的正式版本资产，校验 Release 的 SHA-256，使用可恢复下载和独立版本目录。控制中心显示检查、下载、就绪和失败状态，并允许关闭自动下载或立即检查。中断后续传，下载失败可重试。

安装更新在退出或选择重启更新时完成；后台任务与浏览器中未保存的编辑会延后退出和重启，请先完成或停止任务并保存编辑。关闭浏览器页面会释放该页面的编辑保护。安装准备失败保留旧版入口和数据；上一程序版本保留，启动失败可以从恢复界面打开上一版本。更新复用版本未变的工具、Python 和 pnpm 包缓存，不下载语音模型。

## 验收

`tests/desktop/product.test.ps1` 执行实际安装向导与原生控制中心，另用 Playwright 打开真实浏览器工作台，验证首次创作、本机 CLI 状态、预览、截图、MP4 导出、Remotion 原生执行、编辑与任务保护、窗口收起、重复启动、端口占用、重启后数据保留及异常退出后的语音恢复，保存各页面图像。

`tests/desktop/download.test.ps1` 验证依赖与更新续传、重试、摘要和发布来源；`tests/desktop/github-cli.test.ps1` 在 PowerShell 5 中验证缺失时的实际下载安装、可用 PATH 和跨更新缓存复用；`tests/desktop/update-install.test.ps1` 验证已校验安装程序的成功更新与失败恢复；`tests/desktop/installer.test.ps1` 验证真实 EXE、安装失败、修复、缓存复用、快捷方式和保留数据卸载。测试使用隔离的注册表及快捷方式名称，已有测试安装时拒绝覆盖。
