# 作品工具与工作面板

作品页只显示当前作品的工具，不带作品库或仓库导航。打开作品使用独立标签页，作品库仍留在原标签页。

## 布局

宽屏使用 64px 左侧工具条。上方的“作品”菜单提供作品资料和版本管理；AI、素材、配音直接可见。任务和同步位于下方，导出固定在底部。正常同步状态不抢占主操作区；存在未保存文件、待同步版本、远端更新或错误时显示标记，并通过提示文字说明具体状态。

作品名称与更新预览复用播放器已有的信息行，长名称单行截断且可查看完整名称，不额外增加整行标题。播放、逐帧、时间码、进度条和时间轴显隐仍位于播放器；时间轴手势见 [时间轴与审片操作](TIMELINE.md)。

宽度不超过 900px 时，顶部改为单行 52px 工具栏：作品名称、工具菜单、AI、导出。主操作点击区域不小于 44px。素材、配音、任务和同步位于有文字标签的工具菜单中；长标题省略，不通过换行挤占画面高度。

## 面板与状态

右侧只有一个辅助工作面板。点击 AI、素材、配音、任务或同步切换内容，再次点击当前入口收起。桌面上点击视频不会误关面板，也不会取消任务。面板与播放器之间使用一像素分隔线，鼠标悬停或键盘聚焦时显示可拖动区域；宽度比例和当前打开的工具保存在浏览器偏好中。

工具切换不会重建播放器。AI 草稿、对话、素材引用、素材搜索和列表位置、配音试听结果在当前作品标签页中保留。素材面板的“返回对话”带着已有引用回到原输入；配音的“带入 AI 对话”只填入引用和编排草稿，不自动提交创作任务。

桌面工作面板是非模态区域；窄屏使用可关闭抽屉，打开时背景工具栏与播放器不可操作，键盘焦点限制在抽屉内。关闭后回到打开它的入口。切换或收起工具会暂停该工具中的媒体试听，不影响后台生成任务。

作品资料、版本比较、导出设置和需确认的素材操作仍使用模态窗口，保留原有未保存修改确认规则。后台服务器任务与本机 WebM 状态可在任务面板查看。本机导出依赖当前标签页，关闭页面会中断；服务器任务不依赖页面保持打开。

## 预览、保存与同步

“更新预览”按最新作品代码发起预览构建，不等于保存版本，也不等于推送远端。播放器明确区分“预览最新”“预览待更新”“正在更新预览”“版本核对失败”。构建或本机导出期间禁用重复更新；请求失败后显示错误并可重试。

预览 iframe 和宿主页面通过受校验的 `configure-work` 命令传递作品标题及预览状态，与播放器偏好命令分离，状态更新不重置播放位置或画质。构建请求只接受当前 iframe 窗口发出的无参数消息，不能携带任意作品或执行命令。

播放器运行时版本 9 开始支持该信息行。旧编译预览仍在宿主显示更新入口；用户更新预览后获得新播放器，无需刷新作品页面或重建素材。

## 键盘

Tab 进入工具条后，桌面使用上下键、窄屏使用左右键在入口间移动；Home/End 到首尾。Enter 打开菜单或工具。菜单内用上下键选择，Escape 关闭并返回原入口。工作面板内 Escape 收起；内部模态窗口优先处理 Escape 和未保存确认，不会连带关闭工作面板。

关闭面板不会丢弃草稿，也不会停止 AI、上传或后台任务；停止任务必须使用明确的停止操作。刷新页面后的草稿恢复沿用各工具自身的会话保存范围，临时配音试听仍受其到期时间约束。
