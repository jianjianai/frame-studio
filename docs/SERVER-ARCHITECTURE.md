# FRAME 5 服务端平台

平台保留场景、绝对时间、多音轨、CLI 和逐帧导出协议。作品仓库只包含作品内容；软件、依赖和公共工具由匹配的固定镜像提供。V5 创作、审片、撤销与升级边界见 [V5 升级说明](V5-UPGRADE.md)。

## 运行角色

`studio` 是公开的 React 管理页、Fastify API、WebSocket 和 MCP 入口。它不挂载 Docker socket，不启动特权任务控制器。网页和外部 AI 通过统一业务操作注册器进行校验和调用。

`controller` 是内部进程，使用 PostgreSQL advisory lock 取得调度领导权，管理任务领取、执行容器、恢复、清理和心跳。只有这个角色持有 Docker socket。领导权丢失时停止新的控制副作用，已有隔离执行副本保留。

`executor` 是每项任务的独立非 root 容器，有固定 CPU、内存和进程上限，移除 capabilities，没有数据库、Docker socket 或平台主密钥。它只得到目标作品副本、专用会话、已选连接凭据和任务范围令牌。模型端点等非敏感执行选择在排队时固定，具体不可变执行镜像和工具版本在启动时记录。

`speech` 提供独立 CPU 语音合成；模型和声线在独立模型目录中管理。管理入口复用环境内的 Caddy。Compose 只声明需要长期运行的服务，一次性初始化按需在栈外执行并退出。

## 持久数据与事件

PostgreSQL 保存作品索引、账号连接、任务、事件、语音配置和操作恢复记录；Git 保存作品源码与版本，文件系统保存内容寻址素材及有期限的构建/导出产物。

对话任务不依赖 HTTP/MCP 或浏览器连接。任务和有序事件持久化，重连按事件游标补齐。PostgreSQL NOTIFY 只发送变化对象的标识，WebSocket 只刷新相关作品、任务或会话；旧式表级通知和重新连接保留保守的状态重读。通知不会替代事件表。

任务执行与结果发布是两个阶段。执行完成后，发布使用原结果继续保存；发布失败可以恢复，不重新运行 AI。丢失的执行不会自动重放有副作用的命令。队列诊断报告实际阻塞对象、连接占用、资源和控制器状态，不估计 AI 完成百分比。

## 工作副本和结果应用

每个作品使用独立分支和 Git worktree；任务只复制目标作品。范围、结构、项目检查及预览构建通过后，在作品锁下比较原输入指纹，再可恢复地应用文件并追加 Git 提交。冲突保留隔离副本，不覆盖正式作品。单作品串行，不同作品在资源与连接约束下可以并发。

审片引用可绑定预览任务、源码提交和时间/片段。旧版引用与当前作品不同时，为执行器准备独立参考源码并明确时间归属，由 AI 比较后修改最新作品，而不是把旧时间码静默套用到新内容。

每轮结果保留修改前后版本和实际工具检查记录。本轮撤销在临时索引中逆向合并到当前版本，冲突时不写正式文件，成功时追加历史；多步应用的持久恢复记录用于处理进程中断。版本恢复、逆向撤销和历史只读审片是不同操作。

Git 拉取只允许干净分支和 fast-forward；推送前上传 LFS，绝不强推。素材原件按内容哈希存储，采用到作品时复制进入作品资源目录并记录来源；不能仅凭代码字符串扫描就认定动态资源未使用。

## 鉴权和数据布局

平台目前为单管理员。密码由环境变量配置，变更时撤销旧会话；HttpOnly/Secure/SameSite Cookie、写请求 Origin 校验以及可撤销 API/MCP 令牌继续有效。平台连接凭据加密存储，任务只引用选中的连接。AI 保持直接执行能力，不新增讨论或逐次审批模式；这不取消容器和作品写入边界。预览在无同源权限的 sandbox iframe 中运行。

数据目录：`repos/<uuid>` 管理 Git 引用，`works/<uuid>` 保存作品 worktree，`libraries/<repo>` 保存素材分支；`runs/<task>` 为隔离运行及临时产物，`sessions/<chat>` 保存工具会话，`auth/<connection>` 保存官方凭据，`tools/<provider>/<version>` 保存工具版本。`restores/undo-<request>` 为撤销操作的临时恢复目录，成功后清理，失败时保留。不得把这些操作恢复目录误当成发布前全量备份。

## 发布和验收

应用、控制器与执行器镜像必须匹配，并记录版本与提交身份。数据库在启动前执行带校验和、串行事务的迁移；旧程序会拒绝不认识的新 schema，因此迁移后的回退不是任意切换旧镜像即可完成。

发布默认不执行数据库转储、作品/模型全量归档，也不为备份停机。保留候选构建、独立测试、活动任务检查、必要服务切换及上线健康和功能验收；只有用户另行明确要求才执行备份。旧镜像和已有备份不因升级自动删除。不可逆数据操作与不兼容回退另行确认。

验收包含 `pnpm verify`、隔离候选执行器环境中的 `pnpm verify:release` 和 `pnpm test:workspace`。测试夹具可验证实际 CLI、数据库、浏览器和导出链路，但不替代外部账号真实授权、付费模型能力验收或长片艺术质量审片。实际结果记录在 `records/`，不以历史缓存冒充本轮验证。
