# 创作工具管理

「设置 → 创作工具」管理 Codex 和 Claude Code 的执行版本。模型、提供商与账号登录使用 T3 Code 原生设置及官方 CLI 配置；「设置 → AI 助手」提供原生设置和完整工作台入口，见 [提供商与模型](PROVIDER-MODELS.md)。

进入页面会检查官方 npm 包的 latest 版本。页面保持打开时每 15 分钟刷新一次，重新获得焦点也会重新读取状态。「检查更新」立即重新查询官方版本源。自动检查仅查询版本，不会自动安装。

- 「更新到最新」或「安装最新版本」：服务器先把 latest 解析成具体版本号，再创建后台安装任务。
- 「指定版本」：输入完整版本号，例如 1.2.3、v1.2.3 或 1.2.3-rc.1；可选择以前安装过的版本切换。版本范围、安装地址不受支持。
- 「更新记录」：显示最近五次安装的版本、时间和结果；「详情」查看日志。失败时可直接重试。
- 更新期间显示实际安装阶段。为避免互相覆盖，同一时间只运行一项工具更新；后台任务不会因离开设置页而中止。

版本先在独立目录安装，检查包元数据与 CLI 实际版本均匹配后，再原子切换当前版本。已经启动的创作保持原版本；更新失败不会切换当前版本，已安装的旧版本保留，可通过指定版本重新选择。

官方版本检查成功缓存 15 分钟，失败缓存 1 分钟；并发查询合并，最多读取 1 MiB，超时为 8 秒。检查失败保留上次成功的结果并明确标注，安装 latest 时必须重新确认成功，避免拿过期信息更新。CLI 探测短暂缓存 10 秒；当前版本选择变化时立即重新探测。

桌面/本地模式使用电脑自身的 CLI。页面可以检查官方最新版本，但安装仍通过该工具的官方安装方式完成，不替换本机安装器管理的文件。
