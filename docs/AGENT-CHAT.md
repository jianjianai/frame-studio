# 作品 AI 对话

作品页的 AI 面板嵌入 T3 Code 原生聊天，默认只显示当前作品。所有作品共用一个 T3 服务；打开完整工作台可使用原生文件、Git、终端和设置。提供商、模型和登录通过原生页面与 CLI 配置，见 [T3 Code](T3-CODE.md) 与 [提供商与模型](PROVIDER-MODELS.md)。

播放器“引用当前画面/选段”记录实际显示的版本与位置；素材引用可逐项移除。发送前将引用冻结并绑定当前原生 thread 的命令，提交回执失败时保留草稿和错误，不自动重复发送。历史引用点击可定位对应版本的画面。独立页面没有播放器上下文时不会生成引用。

多个对话共享同一作品目录；AI 保存源码后实时预览观察相同文件。检查结果绑定被检查的 revision，失败保留修改，版本过期明确显示。关闭面板不中断原生回合；后台活动与停止操作通过当前作品的原生 thread 身份限定。

协议与验证证据在 `integrations/t3-code/` 和当次 [维护记录](../records/2026-10-04-t3-code-8.4.0.md)。
