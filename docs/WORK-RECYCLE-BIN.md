# 作品回收站

作品库和仓库作品页均可进入回收站。普通“删除”把作品移入回收站，文件和素材仍可恢复；回收站中的“永久删除”需要输入完整作品名称，会删除作品专属文件、工作树、本地及远端作品分支、历史快照、FRAME 作品绑定、引用、检查、任务与导出记录。原生项目和聊天历史在 T3 Code 中管理。共享素材库、其他作品及仓库主分支、`frame/materials` 分支保留。

“清空回收站”需要输入 `清空回收站` 确认。仓库页只清理该仓库，作品库清理全部仓库。按钮显示完整数量，清理覆盖所有分页，不受搜索和制作状态筛选限制；确认窗口明确显示范围。结果逐项报告失败，失败作品留在回收站，解决原因后可重试。

运行中或待恢复的 FRAME 任务、当前作品的原生回合、终端或权限请求，以及正在读取的预览或导出会阻止永久删除；原生活动状态尚未完整同步时同样拒绝删除。远端分支删除失败时，本地作品完整保留；远端分支已不存在或作品未上传时仍可清理。若远端已删除但本地清理中断，作品暂时不能恢复或修改，继续永久删除即可完成清理。永久删除的旧作品不会被仓库刷新重新导入。

网页、MCP 和远程 CLI 共用以下操作：

| 操作 | 参数 | 结果 |
| --- | --- | --- |
| `works_trash` | `id`、`deleted`；移入时 `confirm` 为作品完整名称 | 移入或恢复 |
| `works_purge` | `id`、`confirm` 为作品完整名称 | 永久删除单个作品及对应远端分支 |
| `works_empty_trash` | 可选 `repo`；`confirm` 为 `清空回收站` | `total`、`purged` 和 `failed`；失败项包含名称和原因 |

MCP 工具加 `frame_` 前缀。CLI 使用 `pnpm --silent platform describe works_purge` 或 `pnpm --silent platform describe works_empty_trash` 查询参数，再调用相应操作。
