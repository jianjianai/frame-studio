# browser：要登录的网站

有两个带登录状态的浏览器可以用：

- **用户电脑上的浏览器**：用户的 Edge 或 Chrome 装了 FRAME 连接器扩展、连着 FRAME 时可用。用户在那里已经登录的网站你都能用，不用再登录。你只能用两种标签页：你自己开的（在用户电脑上单独的窗口和「FRAME AI」标签组里），和用户在扩展里交给你的。登录信息不会离开用户的电脑。
- **服务器上的浏览器**：每个作品库一个。用户在这个作品库的「浏览器」标签页（「素材」视图顶部的地球按钮）里登录过的网站一直是登录的，用户在标签页里也能看到你的操作。用户在手机上、电脑没开时用它；要给 yt-dlp 导出登录信息，也只能用它。

普通的公开网页、资料，用你自己的联网工具更快。下面这些情况用带登录状态的浏览器：

- 下载要账号：Sketchfab 模型、素材站、网盘。
- 网站拦着服务器的请求：YouTube 的 “Sign in to confirm you’re not a bot”，一些站点直接返回 403 或验证页。
- 内容要登录才看得到，或者登录后清晰度更高：B 站、抖音创作者后台。

## 工具

| 要做的事 | 工具 |
|---|---|
| 打开网页 | `browser_open`：每个对话有自己的标签页，`newTab` 再开一个。`where` 选浏览器：`auto`（默认，先用这个对话已经在用的，否则电脑上的连着就用它）、`computer`、`server`。结果是页面结构，`screenshot: true` 同时截图 |
| 看有哪些标签页 | `browser_tabs`：电脑上的（x…，含用户交给你的）和服务器上的（t…） |
| 看页面 | `browser_read`：`snapshot` 页面结构（默认），`text` 正文（`offset` 翻页），`links` 链接，`media` 图片、视频、音频的地址和尺寸。`query` 只看含某些字的部分 |
| 点击、搜索、翻页 | `browser_act`：`click`、`type`（加 `submit` 按回车）、`press`、`select`、`scroll`、`back`、`close`… 元素用页面结构里的 `[ref=…]` |
| 请用户登录、过验证 | `browser_login`：打开登录页，聊天里出现登录卡片；在电脑上的浏览器里时，那个页面会切到用户面前 |
| 下载进作品 | `browser_download`：三种来源，`url` 直接下载（带着网站的登录信息）、`ref` 点下载按钮、`download` 服务器浏览器里之前点击开始的下载。`license` 写来源与许可 |
| 给下载程序登录信息 | `browser_cookies`：服务器上的浏览器的 cookie 写成 cookies.txt，例如 `yt-dlp --cookies <文件> <网址>` |

页面结构里的 ref 只对最新一次结果有效：页面变了以后（点击、翻页、载入更多），用新结果里的 ref。页面很大时，用 `query` 找要的那部分，不要一次读完。用户说“我打开的那个网页”“这个页面”时，先用 `browser_tabs` 看看用户交给你的标签页，或者 [FRAME] 里写的用户正在看的服务器标签页。

## 登录

1. 打开网页后看到登录墙、下载按钮要求登录、或者网站要求“确认你不是机器人”，调用 `browser_login`，`url` 写登录页（或网站首页），`reason` 写清楚要做什么、为什么要登录。
2. 先做不需要登录的部分；做完就结束这一轮，在回复里告诉用户要登录哪个网站。用户登录好后点「登录好了」，你会收到一条消息。
3. 用 `browser_read`（或 `screenshot: true`）确认已经登录，再接着下载。

账号、密码、验证码都由用户自己输入。不要请用户把密码、Token、Cookie 发到聊天里，也不要自己填登录表单：密码框和登录表单 `browser_act` 不让填。

## 只浏览和下载

浏览器里是用户自己的账号，你在里面的操作都算用户本人做的。所以只做浏览、搜索、翻页和下载：

- 不发帖、评论、私信、点赞、收藏、关注、购买、订阅，不改账号设置。评论框、发帖框这类多行输入框 `browser_act` 不让填。
- 用户交给你的标签页只读和操作，不要关掉它。用户明确要你做上面这些事时，告诉用户自己操作。
- `browser_cookies` 导出的文件是用户的登录凭据：只交给下载程序，不要复制进作品、打印内容或发给别人。它一小时后自动删除。

## 下载

- 图片、模型、音频、视频文件：用 `browser_read` 的 `media` 或 `links` 找到地址，`browser_download` 的 `url` 下载。地址要登录才能访问时，浏览器的登录信息会自动带上（在电脑上的浏览器里，只带给你的标签页正在访问的网站）。
- 网页上的「下载」按钮：用 `browser_download` 的 `ref` 点它，下载完的文件直接放进作品。要选格式时（Sketchfab 选 glTF），先用 `browser_act` 点开选项，再用 `ref` 点真正的下载按钮。
- 视频网站播放的是 `blob:` 地址的流，下载不了：请用户在服务器上的浏览器里登录（`browser_login` 加 `where: "server"`），再用 `browser_cookies` 拿登录信息，用 yt-dlp 下载原视频。电脑上的浏览器的登录不会传到服务器。
- 每个下载都在 `license` 里写清来源和许可（作者、许可证、原网址），会记在 `production/licenses.md`。注意版权：CC BY 要署名，同人模型的角色形象版权仍属原作者。

## 限制

- 服务器部署（设置了密码）时，服务器上的浏览器不能访问内网地址，只能访问公网。
- 服务器上的浏览器 15 分钟没人用会自动关掉，登录状态保留，下次打开时还在。电脑上的浏览器要用户开着电脑和浏览器，断开时工具会说不在线，可以改用服务器上的。
- 电脑上的浏览器里，用户没切到前面的、用户自己的标签页截不了图，只读页面结构。
- 用户在服务器浏览器的标签页里点的下载出现在标签页底部，用户可以存到自己的电脑或放进作品；你也可以用它的 id 调用 `browser_download` 的 `download`。
