# svg：和用户一起改 SVG

改作品或素材库里的 SVG 文件前读：用户也会在工作台的 SVG 编辑器里亲手改这些文件。

- 作品和素材库里的 SVG 在工作台里用 SVG 编辑器（SVG-Edit）打开：用户拖动路径节点、改形状、颜色和层次，保存后预览更新；也可以切到「代码」直接改文本。
- 用户可能要亲手调形状的图形（人物、道具）适合画成 SVG：部位分组（`<g>`）并写好 `id`，用户在编辑器的图层和组里认得出来，你也能按 id 找到用户说的部位。
- 用户在编辑器里选中的部位写在“用户正在看”的说明里：文件里有 id 的写 `#id`，没有的写类型（`<path>`）。
- 用户改过的路径是编辑器的写法（`d="m150,260c…"`，相对坐标、逗号分隔），这是正常的：不要改回去，不要重画用户调过的部分，只改用户要你改的地方。
- 编辑器保存时会去掉 SVG 里的脚本和事件属性（`onclick` 等），不要依赖它们。
