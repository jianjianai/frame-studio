# 时间轴与审片操作

宽屏作品页将本作品的操作栏放在左侧，窄屏放在顶部。AI 对话可以关闭并重新打开；作品页不包含作品库导航。视频和时间轴之间仍使用一像素、悬浮显现的可拖拽分隔线。工具分组、共用工作面板与预览更新见 [作品工具与工作面板](WORKSPACE-TOOLS.md)。

时间轴只占用标尺、镜头/音频/字幕轨道和底部可视范围条的空间。轨道名称固定在左边，标尺固定在顶部，音轨较多时不会随纵向滚动丢失。音量、静音和独听作用于当前预览混音，不改写工程源码；浏览器导出使用播放器混音，命令导出仍按工程元数据执行。

## 导航与缩放

底部可视范围条代表整部作品。拖动中间移动可视窗口，拖动两端改变窗口范围（连续缩放）；双击恢复全片。缩到最小后仍保留可操作的中间区域。键盘聚焦范围条后，左右键调整，Home/End 到边界，0 恢复全片。

鼠标滚轮默认横向滚动；Shift＋滚轮纵向浏览音轨。横向触控板手势也支持。Ctrl/Command＋滚轮保留浏览器行为，不劫持页面缩放。播放到视口边缘时跟随播放头；手动平移后暂缓跟随，避免立即抢回视口。

## 定位与选段

播放器上的上一帧/下一帧按钮暂停并逐帧定位。点击播放器时间码打开唯一的定位与选段面板，输入帧编号后按 Enter。视频自身保留独立的拖动进度条，隐藏时间轴也可使用。

在标尺或轨道上拖动可定位；Shift＋拖动框定选段，双击镜头/音频/字幕片段选择该片段的时间范围。在标尺上拖动 I/O 手柄调整入出点，键盘左右键也可逐帧调整。拖动时靠近片段边界会吸附，按住 Alt 临时关闭边界吸附。

聚焦标尺或轨道空白后，Space 播放/暂停，左右键逐帧，Shift＋左右键跳转一秒，Home/End 到起止点，I/O 标记入出点。选段会同步给 AI 对话的“引用选段”。

时间轴显示的是代码工程定义的镜头、音轨和字幕，不假装提供尚未实现的源码剪切、片段重排或持久化时间修改。波形来自工程已有的波形索引；没有波形的代码音频明确标注，不生成装饰性假波形。
