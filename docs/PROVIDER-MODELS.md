# 提供商与模型配置

设置 → AI 助手 → “打开提供商与模型”进入 T3 Code 原生设置。“打开完整工作台”保留原生项目、聊天、文件、Git 与终端。FRAME 不保存第二份提供商目录，不提供 API 地址、密钥、模型发现或账号登录表单。

## 配置与登录

T3 使用真实的 Codex CLI 和 Claude Code。提供商实例、模型、推理档位与默认值在原生页面配置；原生页面没有的配置使用官方 CLI。官方账号登录沿用工具自身授权。API 地址、密钥和自定义模型也使用工具的原生配置，不通过 FRAME 表单转换协议。

服务器 T3 的运行数据与 CLI HOME 持久化在 `/data/ai/t3/`；独立服务升级不清空账号、项目或对话。Windows 使用已安装 CLI 及本机账号配置。工具未安装或授权失效时，按原生错误重新安装或登录；目录能列出模型不代表账号有推理权限。

作品聊天使用原生选择器，历史回合的选择不会因为 FRAME 设置刷新而变化。全局原生设置与作品侧栏访问同一个服务。FRAME 的“创作工具”管理 CLI 安装及独立升级，“GitHub”管理作品仓库账号，“语音引擎”管理配音服务；这些功能不属于 AI 模型目录。

接入及部署说明见 [T3 Code](T3-CODE.md)。
