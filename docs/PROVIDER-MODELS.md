# 提供商与模型配置

入口：设置 → AI 模型。连接与模型目录分离；对话仍绑定提供商，不因默认模型、目录或配置变更而暗中更换账号。

## 默认流程

1. 添加提供商，选择 OpenAI、Anthropic 或自定义 API 模板，填写名称、接口地址和密钥。创作工具分别要求 Responses API 或 Messages API；整理地址不等于转换协议。
2. 新建 API 连接保存后自动打开模型发现。读取期间显示状态；失败保留已保存的连接，显示安全的错误提示，支持重新获取或手动添加。
3. 搜索、筛选、批量选择模型后导入。首次导入自动提出一个默认模型，也可在提交前更换。目录最多保存 200 个模型。
4. 模型行显示关键规格；“编辑模型参数”查看所有已获取字段及来源。默认无需手填参数。列表刷新也能选择已添加模型更新规格。

已保存 API 密钥不会回传浏览器。编辑连接时留空保留原密钥。API 地址会移除末尾 `/models`、`/responses`、`/messages` 或 `/chat/completions`，Claude 连接还会移除末尾 `/v1`，由 Claude Code 自行追加版本路径，避免重复 `/v1/v1/messages`。但仅支持 Chat Completions 的服务仍不能用于 Codex。工具与认证方式不可在已有提供商上更换，需要新建提供商以保持历史会话的凭据边界。

官方账号登录没有可由本工作台直接读取的账号模型目录：使用工具默认模型，或手动补充账号实际支持的模型 ID。公共目录不能证明某账号有权使用某个模型。

## 自动规格与来源

规格包括上下文窗口、最大输入和输出 token、输入输出模态、视觉/推理/工具调用/结构化输出能力，以及输入、输出和缓存参考价格。`max_input_tokens` 仅记录为最大输入，不冒充总上下文。支持能力只由显式字段或完整的能力/参数列表判定，不根据模型名称猜测。

数据优先级为：**显式手动覆盖 → API 返回 → 公共目录精确匹配 → 未提供**。各字段独立显示来源；未提供既不是零，也不表示不支持。零价格和 `false` 能力是有效值，不会被公共参考覆盖。

公共补齐使用服务端下载的 `https://models.dev/api.json`，缓存一小时；短暂失败负缓存 30 秒，不阻断已有 API 结果导入。仅请求这个固定公共 URL，不向其发送用户密钥、接口地址、模型 ID 或对话内容；可在连接高级选项中关闭。先按官方提供商匹配；自定义网关只接受无歧义的规范 ID 或明确的聚合目录 ID，不猜别名。

OpenRouter 风格 `pricing` 的每 token 美元价格统一换算为美元 / 百万 tokens；models.dev 的 `cost` 本身按百万 tokens 记录。公共目录中的上下文、能力和价格均为参考，不代表网关的实际部署、倍率、收费或账户配额。

这些字段是**模型规格**，并非已执行的生成参数：不会把参考上限强行作为每次任务的输出长度，也不添加没有执行层保障的温度、推理强度等控制。模型 ID 仍按原逻辑发送给 Codex / Claude Code。模型出现在目录中不代表已经通过这些工具的调用兼容性测试；“测试模型”是独立、显式的少量生成请求，可能计费。

## 同步与手动兜底

发现模型不会直接写入目录，只有确认导入才保存。再次获取清空本次选择并读取最新配置版本。批量选择受剩余目录容量约束；已保存模型仍可选择更新，不占新名额。

同步不移除上游未返回的旧模型，不重置启停状态，不改掉自定义显示名称，也不清除手动覆盖；未被选择的模型保持不变。已有默认模型保留，除非用户在导入确认中明确更换。

手动添加只需 ID，名称和规格均可省略。高级项会预填现有自动值；编辑后标为手动覆盖，未来同步保留。“恢复自动”移除对应覆盖值，重新采用自动规格。清空一个数值表示用户明确将它标记为未知。

保存采用配置版本比较。若其他页面修改配置或测试结果导致版本变化，旧编辑不会覆盖新状态，界面提示重新打开或重新获取。

## 提供商删除

详情底部提供独立删除入口。确认框展示历史对话数量、活动任务和进行中的授权，需要输入完整提供商名称。排队、运行、取消中、发布中、发布失败待处理的任务，以及正在进行的授权，会阻止删除；先完成、停止或解决这些工作。

服务端以提供商级 PostgreSQL advisory lock 协调删除、任务最终入队和官方授权开始，并再次校验名称、版本和活动引用。删除后：

- 模型目录与 API 密钥从加密配置中清除，授权信息清除，并移除该提供商的本地登录目录。
- 不删除作品、任务、事件及对话。仅留下无凭据、不可启用的内部标记行维护历史外键；列表、模型选择和新调用不再包含它。
- 旧页面保存、启用、重新测试或继续发送都会明确失败，不能恢复已删除提供商。已持久化请求的幂等重试仍可取回原任务，不会重复执行。
- 发起删除的浏览器会清除这个提供商对应的默认模型及收藏，不影响其他提供商。旧对话仍可查看，继续创作需要选择其他提供商并新建对话。

本地凭据目录若因文件系统权限不能清理，删除返回明确警告，不宣称已清理成功；数据库凭据仍会立即失效。没有自动切换到其他账号或清除其他提供商目录的行为。

## 网络边界与回归

发现只访问已配置端点，不跟随重定向或 API 提供的任意分页 URL。OpenAI 兼容分页使用 `after`，Claude 使用 `after_id`。总读取时限 20 秒，每页最多 2 MiB、最多 10 页或 1000 个去重模型；部分分页失败或达到边界时明确提示，保留已读取结果。公共补齐另限 8 秒及 24 MiB。错误响应正文不传给前端；只有服务端构造的安全错误允许在 WebSocket 中显示。

回归测试：

- `tests/server/provider-metadata.test.mjs`：字段解析、单位、优先级、精确匹配、未知值、分页边界、脱敏和覆盖同步。
- `tests/server/provider-lifecycle.test.mjs`：真实 PostgreSQL 的删除锁、活动任务阻断、历史及幂等保留、凭据清除、旧请求不能恢复连接。
- `tests/server/provider-settings-browser.test.mjs`：真实页面与 WebSocket、模拟模型 API 的完整配置流程，含 1440/768/390/320 像素布局、错误重试、手动兜底、删除保护和偏好清理。
- 原有 `ai-models`、`ai-workbench-browser` 回归继续覆盖旧连接、聊天选择与任务模型冻结。

协议依据：[OpenAI Models API](https://developers.openai.com/api/reference/resources/models)、[Claude Models API](https://platform.claude.com/docs/en/api/models/list)、[OpenRouter Models API](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties) 和 [models.dev](https://models.dev/) 的公开字段。接口未提供的规格不保证一定可以补齐。
