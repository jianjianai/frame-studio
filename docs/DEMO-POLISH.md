# 三个 Demo · 第二版精修记录

本轮保留 FRAME 工作台的页面设计与通用播放器，改动集中在《风的邮差》《日光快线》《一颗种子的四季》的音乐、声音细节、画面与摄影机。Demo 的身份不再作为降低制作质量的理由；它们仍是 32／36 秒的原创艺术短片，不冒充已经完成的长篇科普影片。

## 1. 音乐先行

替换旧版以相近合成音色和循环动机为主的配乐。三首曲子分别写旋律、和弦转位、乐句长度、配器出入、力度和表情，采用本地采样乐器离线演奏，并保留可继续制作的 MIDI 与乐谱事件。

| 作品           | 音乐安排                                                                                                             | 声音与动作                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 风的邮差       | D 大调室内乐。钢琴引子、长笛回应，竖琴与弦乐在跨海段展开；抵达时完成终止式，再保留自然尾音。                         | 纸张擦过空气、林间风声、远处鸟鸣、海湾环境与投递触点；声音与投递动作处于同一时间轴。 |
| 日光快线       | F 大调轻爵士，轻微摇摆节奏。钢琴、尼龙吉他、低音提琴、颤音琴、单簧管和刷鼓轮流承担主题与回应，归站以 F6/9 和弦结束。 | 起站汽笛、蒸汽、轮轨与轨缝节奏；轨缝声和车辆使用同一条行驶距离曲线，而非独立节拍器。 |
| 一颗种子的四季 | G 大调三拍子。稀疏钢琴起句，雨中转向较深的音区，大提琴与弦乐随生长进入，长笛在开花时展开，最后回到安静的主和弦。     | 雨滴、触地、叶片和花瓣声，以及靠近、停留、离开的蜂鸣变化。                           |

这是数字采样乐器演奏，不是真人乐团录音。旋律、编配和合成动作音效与第三方乐器采样的权属分开记录；GeneralUser GS 的原始许可及作者关于历史采样来源的不确定性完整保留。详见 [配乐工程](../production/music/README.md) 与 [素材说明](../public/ASSET-LICENSES.md)。

## 2. 画面与摄影机

**风的邮差：**重新组织小镇、树林、桥梁、海岸和灯塔的空间。海湾真正留出开放水面，增加岩岸、海面反光、层次化植被与纸张质感。去掉会露出直切边缘的旧前景贴图。飞机在灯塔旁连续折回信封、落入信箱，随后灯窗由暗变亮，不再只悬在灯塔上结束。

**日光快线：**摄影机始终沿轨道外侧连续跟拍，穿过山体的直线插值改为外侧环绕，加入近距离经过和高位拉远。列车采用轨道弧长保持车距，补充车钩、可见轮辐、司机挥手、灯、旗和花圃细节。蒸汽从历史出生位置升起，不再黏着当前车头一起移动；列车平稳加速、巡航并归站停稳。

**一颗种子的四季：**从几乎固定机位改为落种、根系、茎叶和花朵的连续近景。加强土壤层理、细根、叶脉、露珠、雨滴涟漪、花瓣层次与蜜蜂落花的接触感。花朵成熟为绒球后再放出新种子，保留同一株艺术化植物的形态联系。它是生命循环的艺术寓言，不声称是精确的植物学时间模型。

三片仍从绝对时间计算全部画面，支持倒拖和逐帧；没有引入独立的场景计时器。新摄影机曲线在关键点保持位置和速度连续，并检查不超越设定构图范围。

## 3. 工程与可维护性

- `pnpm music:build` 重建三首配乐；也可传入单个 Demo 标识。采样引擎仅为开发依赖，不进入浏览器播放包。
- `scripts/music/` 为作曲与渲染源，`production/music/` 为 MIDI、乐谱、许可与母带报告。
- 音乐、音效和母带前混音分轨位于本地 `exports/demo-polish/audio/`。
- `pnpm assets` 不再覆盖精修母带或人工维护的许可记录；新增回归测试验证这一点。
- `AGENTS.md` 已写入“Demo 也需要高标准，优先音乐、其次画面和运镜”的制作约定。

## 4. 完整视频交付与核验

三个完整视频均位于本地 `exports/demo-polish/`，带配乐、音效与中文字幕，不是只有几秒的测试片段。

| 文件               | 画面               |  片长 | 实际解码帧数 | 音频             |
| ------------------ | ------------------ | ----: | -----------: | ---------------- |
| paper-wings-v2.mp4 | 1920×1080 / 30 FPS | 32 秒 |          960 | 48kHz 双声道 AAC |
| sunny-rail-v2.mp4  | 1920×1080 / 30 FPS | 36 秒 |         1080 | 48kHz 双声道 AAC |
| tiny-seed-v2.mp4   | 1920×1080 / 30 FPS | 36 秒 |         1080 | 48kHz 双声道 AAC |

三个文件均完成 FFprobe 逐帧计数及 FFmpeg 全片解码，无解码报错。视频中的音轨按同一时间原点解码后，与母带的相关性均高于 0.9999，用来确认封装的是这轮新配乐、没有整体音轨偏移；该检查不被当作艺术性的声画设计评分。

已查看最终编码视频的开头、中段与结尾画面，包括信封投递前后灯光、列车近距离经过、蜜蜂落花及绒球放种；另外检查未烧字幕的实时渲染关键帧与多次反向跳转。

完整输出的机器可读核验记录见 [DEMO-DELIVERY-VERIFICATION.json](DEMO-DELIVERY-VERIFICATION.json)。单个 `.mp4.render.json` 保存在导出视频旁边，包含导出参数和 FFprobe 结果。视频、分轨、乐器库缓存及临时检查图片不加入源码 Git。

## 5. 自动化验收

本轮新增 15 项单元检查和 3 项完整播放浏览器检查。原有播放、暂停、倒拖、逐帧、倍速、循环、字幕、PNG／SRT、移动布局及完整 WebM 录制检查继续保留。最终对仅含本轮提交内容的独立快照完整执行 `pnpm verify`：类型检查通过、49 项单元测试通过、生产构建通过、11 项浏览器测试通过，命令退出码为 0。浏览器测试包括三片从头到尾播放、关键乐句处反向跳转，以及完整 32 秒 WebM 录制。

隔离副本只将测试预览端口改为 4177，不停止其他任务的服务器；未把并行制作中的其他影片纳入本轮提交。验收期间发现原有 WAV 时长检查错误地假定固定 44 字节文件头，已纳入实际 RIFF 分块解析修正，再运行全套验收通过；没有通过跳过测试或降低音频规格来回避问题。
