## 十类设计问题修复

1. 弹窗反馈：通知进入最上层 dialog，保存失败也在表单中持续显示；实际命中检查确认通知不被遮罩覆盖。
2. 窄屏：移除 807px/500px 式固定堆叠逻辑，作品页无侧栏；320、390、768、1024、1280、1440px 检查页面无横向溢出、输入框可见。
3. 导出：统一分辨率、帧率、范围、字幕和执行位置；准确区分排队、运行、停止中、已停止、失败、完成；支持取消、清理确认、本机结果重新下载。导出期间冻结预览替换，避免 AI 新结果刷新 iframe 中断本机导出。
4. 表单保护：未保存内容关闭前确认，失败保留输入；保存成功清除脏状态；敏感字段不写入浏览器持久草稿。
5. 顶栏主次：保留同步、任务、AI 和导出；辅助操作收进“更多”。同步异常/未保存/待同步使用可读文字与强调色，不再淡得像禁用。
6. 审片上下文：明确引用时间/选段，不把时间伪称截图；可移除、回跳、保留历史范围和素材名称；重试沿用原上下文。
7. 时间轴与版本：当前镜头信息、延迟生成的独立缩略图、嵌入模式画质切换；历史版本只读生成、变化文件比较、同时间对照，恢复必须另外确认。
8. 首页与空状态：显示制作状态和活动，支持状态筛选；区分没有作品、没有搜索结果、请求失败；首次创建可直接添加仓库。
9. 素材与配音：区分仓库素材、本作品资源、给对话的引用；引用不会暗中复制。配音先试听、再采用同一份文件，不二次合成；编排位置只写入 AI 草稿，用户确认后发送。
10. 对话排版：安全的标题/列表/粗体/代码/链接呈现，禁止原始 HTML 执行及危险链接；改善文字尺寸，支持时间定位和复制结果。

### 回归中修正

修正版本弹窗重试按钮括号错误、表单文本域标签与默认值混合导致的定位问题；补齐旧浏览器回归与新交互的对应关系。测试专用 Vite 播放器允许 opaque sandbox origin，与生产预览的资源响应一致；未放宽生产权限。

Windows 缺少 Git LFS 导致首次服务端同步回归失败。只在本任务 `.cache/frontend-validation/tools/` 下载官方 v3.7.1 portable 包并核验 SHA-256，临时加入测试进程 PATH，没有全局安装、没有改用户 Git 配置。之后完整服务端回归退出 0。

历史快照额外支持 LFS 指针还原：仅向隔离输出写真实媒体；必要时只补取所选版本当前作品范围内的对象，校验大小与 SHA-256，不改当前作品 HEAD/index/文件。缓存、补取路径和损坏内容拒绝均有用例；补取网络动作使用测试替身，未访问真实历史远端素材。

官方包来源：`https://github.com/git-lfs/git-lfs/releases/tag/v3.7.1`，Windows amd64 ZIP 校验值 `8683cdc3d6c029b49393dcebbaa6265bd6efd9abdcf837be855b4cd42e5e80b6`。
