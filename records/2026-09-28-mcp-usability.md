# MCP 连续制作体验优化

## 目标与设计

- 检查完成但不通过使用普通结构化结果；执行检查失败保留明确错误。严格范围判定不放宽，另外分类并截断外部工程和公共文件变更，不能把路径分类当成作者归属。
- 项目操作锁增加实例身份、锁身份和关联任务，提供查询、同实例任务取消和确认进程已退出后的恢复。存活、未知状态、遗留事务和旧格式锁不自动删除。
- 图片默认提供原生内容、尺寸和内容指纹；提供纯图片兼容模式、元数据模式及有界缩放。图片成功返回不等于已完成模型视觉验收。
- 本机远程配置开放全部项目、完整制作读写权限；OAuth/Bearer 身份认证继续有效。逐次工具审批由 AI 客户端决定，工具的读写标注保持真实。

## ChatGPT 应用权限

按用户明确要求，已通过应用权限管理接口将 Frame Studio 的专属权限更新为 `full_access`，回读结果为 `Allow all actions`：ChatGPT 不再逐次询问读取或执行操作。全局应用权限不变。这是实际客户端设置，与 `.env` 的项目范围和 OAuth 登录分开管理。
