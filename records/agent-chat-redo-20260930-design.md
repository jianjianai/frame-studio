# Agent 聊天重做：前置产品评审与验收矩阵

## 基线与边界

用户打回前一版，要求从 main 重建独立工作树，重点是 Agent 完整交互，而非再换一套聊天样式。工作树 `frame-studio-agent-chat`，分支 `feat/agent-chat-redo-20260930`，初始 main 提交 `d99df25`。主工作区存在他人暂存的 V5 合入，另有提供商与源代码管理并行任务；不带入其未提交内容。集成时只跟进已提交 main，保留这两项产品能力。

不新增讨论模式、人工审批或自动切换提供商。AI 在现有作品隔离边界内直接执行、验证后应用。需求澄清是与人互动，不是执行权限审批。

## 修改前审查

- `agent-events.mjs` 一次只能返回一个事件，Claude 同一响应中的文字和多个工具块相互遮蔽；缺失文件差异、完整工具参数、错误状态与计划。
- `WorkChat.Turn` 分别聚合文字和工具后统一展示，打乱原本的执行顺序。制作过程只是一个文本日志抽屉，不能回答“在做什么、动了哪里、命令是否成功”。
- Codex 非交互 exec 与 Claude 一次性 stdin 无法将追问回答送回当前运行。仅画问答卡片不能解决问题。
- 没有可靠的待回答、成功、失败通知及通知历史；用户必须一直盯着聊天窗口。
- 只有简单 Markdown 展示。长代码/多步骤/多文件没有合适的阅读、复制、搜索与收拢逻辑。

## 设计决定

1. **连续的消息时间线。** 文字、公开思考摘要、工具/命令/文件/计划依照真实首发顺序排列。同一条目增量更新而不复制最终全文。保留原始块身份与父工具关系；只展示公开摘要，不读取加密或原始内部推理。
2. **渐进展示执行过程。** 当前步骤直接可见；连续已完成步骤折叠为一行，用户展开后保持其选择，不随更新抢滚动。错误与待回答不藏起来。最终回复与本轮文件清单留在可见层。
3. **命令和工具各有其语义。** 命令展示命令行、工作目录、实时输出、退出码、用时，工具展示名称、输入、结果、失败原因。不是把所有事件都标成完成。
4. **文件变更可审查。** 从真实文件操作事件及隔离工作区差异获得文件列表、增删行、变更类型，点开查看逐行差异。明确修改中/完成/失败及二进制、截断、未提供差异等边界。
5. **提问是真实停等。** Codex app-server 双向 RPC、Claude stream-json 控制响应和统一 ask 工具均接入持久化问题。选项/多选/自由回答在聊天内提交，继续同一任务。刷新不丢问题，重复提交幂等，跨任务拒绝，取消后不能再答；等待不消耗正常执行时限。凭据不通过聊天收集。
6. **通知不打断。** 待回答、完成、失败写入通知中心，点击定位对应作品/对话/轮次。网页内提示默认可用；桌面通知只经用户主动授权，可选择仅窗口失焦时提醒；不默认播放音效。关闭浏览器期间的事件留待重开查看，不宣称有离线 Web Push。
7. **输入与阅读互不妨碍。** 继续保留提供商分组模型选择、引用、独立草稿和队列。正在等回答时明确区分回答与排队新要求。支持内容搜索、代码复制、键盘操作、窄屏和内容过长保护。

## 不是本次验收的替代品

构建通过、纯静态截图、模拟收到一个问答对象、模型测试接口返回 READY，均不能证明 Agent 交互可用。不得把它们表述为原生模型完整执行验收。

## 验收矩阵

| 场景 | 必须观察到的行为 | 证据 |
| --- | --- | --- |
| 文字→思考→工具→文字→文件→最终回复 | 顺序正确，更新不重复，全部内容块保留 | 归一化/归约测试、浏览器 |
| 长命令输出、非零退出码、并行工具 | 输出可展开复制、状态准确、不撑破布局 | 流式协议与浏览器 |
| 修改/新增/删除/二进制文件 | 真正差异与统计，拒绝未知文件及越界 | Git 工作区测试、浏览器 |
| 单选/多选/自由回答与多题 | 校验、草稿、原任务继续、答案回执 | 真后端、真实 CLI 对接本地模型端点 |
| 回答前刷新、断线、丢确认、双标签竞争 | 持久问题恢复；同请求不重复；冲突有明确信息 | 数据库、WebSocket、浏览器 |
| 问题待答时停止任务 | 问题结束，执行器退出，无挂起或自动采用 | 执行器、数据库 |
| 跨作品/任务回答、恶意字段 | 拒绝越权和非法结构，不泄露密钥 | API/契约测试 |
| 关闭 AI、切换面板、窗口失焦 | 执行不停止，重要事件通知，点击准确定位 | 通知中心/浏览器 |
| 长会话、阅读旧消息、搜索、代码与 diff | 不强拉滚动，折叠状态稳定，必要时按需加载 | 浏览器与性能边界测试 |
| 1440/1024/768/390/320 宽度与短屏 | 输入/提交/停止可达，无横向页面溢出 | 截图与布局断言 |
| 旧历史消息、模型选择、V5 结果 | 兼容已有数据，不退化已合入工作流 | 全套回归 |
