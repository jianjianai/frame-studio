## 新增行为与注意事项

`publishing` 表示执行已结束、正在保存/发布，不能再按普通执行任务取消；连续三次发布失败后进入 `publish_failed`。这两种状态保护恢复副本，不自动清理，同作品新执行暂缓。处理错误后使用后台任务中的“重试保存结果”或 `task_retry_publish`。不能把该操作当作重新生成内容。

资料版本检测是兼容性可选参数 `expectedRevision`；网页资料表单会传递它。旧客户端仍可省略，但同字段并发更新没有强制冲突提示。不同字段更新使用锁内最新资料合并，避免旧快照覆盖。

旧预览仍可播放，但明确标注需要刷新；不会为了提示新版本而偷偷重新执行 AI。源码哈希针对当前作品计算，尚未进行真实大项目性能验收。

`FRAME_TASK_CONCURRENCY` 默认 2，范围 1–8；当前架构仍按单控制器部署。`FRAME_MIN_FREE_BYTES` 默认 1 GiB，不足时只暂停新任务出队，不删除作品或误杀已有任务。`/healthz` 为轻量存活检查，`/readyz` 为依赖/空间就绪检查；详细信息需登录后查看设置 → 运行状态。

类型检查按增量补齐：新增 JSDoc 类型检查覆盖草稿快照和事件加载，不声称整个既有 JavaScript 平台已经全部类型化。平台全量 JS/JSX 使用语法/相对依赖检查。

## 统一验收入口

需要独立 PostgreSQL 测试数据库、Node/pnpm、Chromium、FFmpeg/FFprobe。测试会清理测试数据库中的表，严禁配置生产库。

```powershell
$env:FRAME_TEST_DATABASE_URL = 'postgres://frame:<测试库密码>@127.0.0.1:5432/frame_test_review'
pnpm verify
```

完整发布验收在隔离 Linux/WSL 环境设置 `FRAME_TEST_EXECUTOR=1`、`FRAME_TEST_HOST_ROOT`、候选 `FRAME_EXECUTOR_IMAGE` 后运行 `pnpm verify:release`。镜像流水线依赖该入口。`pnpm test:server:light` 是显式允许缺少集成环境的开发入口，不能当发布结果。

唯一明确可选的发布用例为用户提供 GeneralUser 音色库；配置 `FRAME_TEST_SF2` 后启用，未配置时单独列明跳过，生成音色库回归仍执行。旧作品使用临时 checkout 中的 `pnpm verify:content`，不把内容提交进平台仓库。

详见 `docs/VERIFICATION.md`。

## 验收重点

| 场景 | 需要确认 |
|---|---|
| 启动中取消 | 准备前、准备中、认领后取消，最终不被恢复成 running；实际容器停止行为正确。 |
| 并发资料更新 | 标题/说明分别保存不互相覆盖，旧版本资料表单返回冲突，SQL/文件中断可恢复。 |
| 跨作品 | A 制作时 B 仍能编辑；A 自身仍受锁与发布恢复保护。 |
| 监控故障 | 半写进度 JSON、日志失败、Docker 暂时不可达不误杀正常任务；恢复后能继续跟踪。 |
| 发布恢复 | 文件应用后 Git 失败、预览发布失败、控制器重启，恢复同一结果且不重复调用 AI。 |
| 预览一致性 | MCP 修改源码、恢复版本、超过 100 个历史任务后，仍正确显示当前预览与过期状态。 |
| 长对话/慢网 | 上百轮历史、断线重连、订阅拒绝；发送后继续输入或切换对话不丢草稿，回包丢失重试不重复提交。 |
| 封面边界 | SVG 与伪装扩展名均返回 WebP；解码失败明确报错，素材原件不被修改。 |
| 平台播放器 | 新增临时短片用例检查跳转一致、有声播放、取消后再导出、视频帧数及音频流。 |
| 数据与运维 | 新/旧数据库迁移、重复启动、错误校验和；低空间出队保护；备份校验和隔离恢复后的主密钥/作品/素材一致性。 |
