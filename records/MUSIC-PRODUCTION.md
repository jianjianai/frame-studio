# 三个 Demo 的配乐工程

三首短曲分别作曲与配器，不将同一段循环换调后铺满片长。此目录保存乐谱事件、可导入 DAW 的 MIDI、乐器库许可和实测母带报告。它们仍是数字采样乐器的离线演奏，不是真人乐团录音。

## 配器与结构

| 作品           | 速度／拍号             | 配器                                           | 乐句发展                                                               |
| -------------- | ---------------------- | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 风的邮差       | 96 BPM，4/4            | 钢琴、竖琴、长笛、弦乐、大提琴、钢片琴         | 钢琴动机 → 木管回应 → 弦乐托起跨海段 → 投递时的 D 大调终止与自然尾音   |
| 日光快线       | 112 BPM，4/4，轻微摇摆 | 钢琴、尼龙吉他、低音提琴、颤音琴、单簧管、刷鼓 | 起站引子 → 颤音琴主题 → 单簧管桥段与借用和声 → 归站的 F6/9 终止        |
| 一颗种子的四季 | 90 BPM，3/4            | 钢琴、竖琴、大提琴、柔和弦乐、钢片琴、长笛     | 稀疏三音动机 → 雨水与低音区 → 根系的弦乐 → 绽放高潮 → 留白与新种子离开 |

各项目的 `score.mjs` 中的音符、和弦转位、时值、力度、声像、表情与乐句落点是可编辑源。每首的 `.score.json` 是生成后的事件记录，`.mid` 可导入音乐工作站继续精修；最终效果还取决于所选乐器音色。

## 重建

```powershell
pnpm music:build sunny-rail
pnpm music:build tiny-seed
```

需要 Node、pnpm 依赖和 FFmpeg。首次重建下载固定版本的 GeneralUser GS 乐器库到 `.cache/soundfonts/` 并校验 SHA-256；缓存有效时无需再次下载。乐器库不是网页运行时依赖，不放入 `public`，也不提交 Git。播放已经提交的 WAV 不需要下载或运行采样引擎。

输出：

- `public/audio/<id>.wav`：48,000 Hz、16-bit、双声道最终母带，保留原播放器路径。
- `exports/demo-polish/audio/<id>-music.wav`：纯音乐分轨。
- `exports/demo-polish/audio/<id>-foley.wav`：环境／动作音效分轨。
- `exports/demo-polish/audio/<id>-premaster.wav`：母带处理前混音。
- 本目录的 MIDI、乐谱 JSON、[历史配乐报告](music-render-report.json)；`public/waveforms.json` 同步更新。

此命令是明确重建现有三个 Demo 的母带，因而会替换同名 WAV；不会修改其他作品的音轨。旧 `pnpm assets` 已停止重写音乐，只负责插画、模型解码器与素材索引，避免一次资产重建退回旧配乐。

## 混音与同步

采样乐器使用各自声像、力度和空间发送；弦乐在乐句之间有表情包络。音符时间与力度使用固定的细微偏移，不在每次重建时随机变化。

风、纸张、海湾、汽笛、轮轨、雨滴、叶片与蜂鸣是本项目合成的动作声音，不宣称现场录音。列车的轨缝声与车辆共用 `projects/sunny-rail/motion.mjs` 的距离曲线；车辆按轨道弧长排列，不再用固定角度代替车距。蜜蜂落花期间减弱蜂鸣，离开时恢复。

混音采用低频清理、轻微均衡与两遍响度处理，目标 -18 LUFS、真峰值不高于 -1.8 dBTP；实际结果见 [历史配乐报告](music-render-report.json)，不把目标值当作实测值。保留作品之间合理的动态差异，不强行把抒情段压成一条平线。乐曲自行完成终止式，再让自然尾音结束，末端仅做防截断短淡出。

这些历史母带仍可作为单条文件音轨使用；播放器现已支持文件与代码生成的多音轨，详见 docs/AUDIO.md。

## 质量检查

新增测试检查完整的音符／MIDI事件、乐曲区别、母带实际采样率和时长、非静音、峰值、单声道兼容性、安静结尾，以及音频文件 SHA 与实测报告对应。艺术完成度仍要结合完整影片和实际听感判断，数值通过不能替代审美验收。
