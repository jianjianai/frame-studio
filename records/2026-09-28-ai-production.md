输入依据：两次制作反馈《制作科技动画成品》《制作完整动画成品》及项目内生产记录；核对了导出会话仍使用开发服务器、全项目注册/检查、浏览器测试模板路径错误等事实。历史失败不能直接证明热更新是唯一原因，改造以固定输入和执行隔离为验收目标。

设计、接口和可复制命令见 [AI 制作指南](../docs/AI-PRODUCTION.md)，MCP 接入见 [MCP 文档](../docs/MCP.md)。这是已实现并实测的公共维护版本；尚未提交或合并到原 checkout，也未修改个人 MCP 配置。

## 已实现

- 正式渲染从目标作品、公共运行源码、二进制资源和依赖锁文件生成输入清单，复制字节并核对哈希，构建独立静态页面；不使用开发热更新或全项目注册表。独立端口、缓存和错误收集，结束清除自己的临时资源。依赖安装仍共享，渲染期间不得修改 node_modules。
- 单项目 dev/typecheck/test/test-e2e/build/validate；列表单独报告损坏工程，其他工程错误不阻塞目标。修复新工程浏览器测试模板的引擎引用路径。workspace 可以保留未提交源码并建立独立项目副本和本地 Git 基线。
- CLI 与 MCP 复用 ProjectService、渲染/审片/验证服务和 Jobs。支持带哈希的搜索、读取、精确局部补丁、批量编辑、检查点、历史和显式版本恢复；保留冲突检测、失败回滚和项目路径边界。
- review 返回连续短片、带时间组帧、独立 PNG、混音、独立音轨、字幕和版本信息；compare 返回同一时间段的 A/B 循环播放器；review-note 把意见绑定到时间和输入版本。MCP 可取原生 PNG，也可显式请求有限大小的原生 WAV 音频。
- export 先做真实场景/音频的短段编码封装，再按整数帧分段；恢复逐段验证内容哈希与帧数，拒绝变更输入或参数。成片发布前完整解码、实际计帧及声画时长检查；视频分段拼接、声音整体混合，避免逐段 AAC 的接缝。排他锁避免并发恢复；后台取消仅清理自己的锁和进程树。
- 浏览器导出实际试编码 VP9/VP8，保留尺寸和帧率；失败报告明确。支持通过有背压的 StreamTarget 写到用户选择的文件，取消中止写入；内存下载仍限制 256 MiB。
- 通用绝对时间 PCM Worker，分块、缓存限额、取消、超时与释放；不改动原采样乐谱的状态推进逻辑。播放器调试接口可等待声画准备、定位捕获、倍速、分轨、读取性能/错误；场景可选暴露有范围的参数和辅助层。
- 旁白逐句实测时长、内容缓存、重做失效句子、重叠与预算检查、不同采样率统一混音、版本化音轨/SRT/字幕时间线。通过项目自有提供器或已有声音文件工作，不内置在线账户。
- `film help --json`、上下文命令提示、结构化错误和旧导出命令 JSON 包装；后台 job 可在启动命令退出后继续，提供心跳、状态、取消和有限日志。28 个 MCP 工具，CLI 可独立完成制作流程。

## 验证中发现并修复

1. 旁白测试中无限补静音滤镜与时间裁剪组合未按预期结束，曾产生约 25.6 GB 的测试临时 WAV。停止了确认归属本测试的编码进程并清理夹具；修为有限补齐、采样数裁剪、显式输出时长/字节上限、超时及最终时长检查。后续重跑通过，44.1 kHz 提供器也通过。
2. 一项已有资源测试运行两个外部 Node，在负载下耗时约 6.6 秒超过原 5 秒。仅该项超时改为 15 秒，断言保持不变；随后完整 verify 通过。
3. 正式导出新增规划与快照版本一致性复查、同清单排他锁、嵌套资源清理；后台状态不会在清理失败时继续声称成功。真实取消、超时、断开测试覆盖已有进程树清理路径。
4. 命令行补齐 doctor/poster 的 JSON 参数处理、无效参数结构化错误，以及损坏单项目的独立错误报告。

## 明确边界

- 自动化分别记录结构、运行、媒体与内容审阅；`not_run` 不会因为生成文件或通过响度检查变成“已审看/已试听”。主观质量、科学事实正确性和整片节奏仍需实际审阅。
- 模型无关的 MCP 使用真实官方 SDK 客户端做过协议/媒体返回测试；未另外调用 GPT-6 Astra 完成端到端创作评测，也未连接个人在线 TTS 服务。不能据此宣称对所有宿主音频显示能力或所有模型创作质量已验收。
- 流式编码在真实浏览器用 WritableStream 验证；操作系统原生保存对话框由用户选择目标，未自动操作该系统对话框。
- 项目代码、旁白提供器与共享依赖按可信本地代码运行；路径边界不是 OS 沙箱。异常断电/宿主整体崩溃留下的操作锁需核对现场再恢复，不按旧 PID 杀进程。
- 参数调节是临时调试值，确认后应写回作品源码/参数文件；原有有状态采样乐器的未缓存远端跳转仍需推进合成状态，不承诺恒定延迟。
- 实现保留在 codex/animation-mcp 工作树；没有改动原 checkout 的两个未跟踪作品，没有替用户合并、提交或修改个人客户端配置。
