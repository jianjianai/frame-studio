# 访问设置优化 · 2026-09-30

- 基线：origin/main `fc1bf50`，工作树：`frame-studio-access-settings`，分支：`fix/access-settings`。
- 按本次要求使用独立工作树并进行轻量验证。

## 改动

- OAuth 连接查询在 LIMIT 之前排除 revoked 记录。保留数据库中的撤销状态与令牌族保护信息，不迁移或删除授权数据。
- 前端兼容过滤已撤销记录；撤销成功立即移除对应连接/令牌，失败保留当前项目并显示错误。
- 访问设置拆为独立组件与局部样式，分为连接入口、OAuth 连接、访问令牌、登录密码说明。
- MCP 地址可复制；连接显示状态、授权时间与有效期；令牌显示创建时间与数量。
- 创建令牌使用弹窗，明文仅在成功弹窗中显示，关闭后清除；复制失败提供手动复制提示。
- 补齐加载、错误重试与空状态；宽屏授权与令牌并排，窄屏纵向排列。
