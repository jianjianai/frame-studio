- 600 ms RTT、96 KiB/s：真实 H.264/AAC 源跳转、取消与连续跳转、两实例共享源，仅一次 Range 请求；释放后全局预算归零。

## 边界

源码需要增量编译及候选初始化，仍可能是数秒；首次代理要转换与下载。带宽小于全部活跃媒体码率时无法保证零等待，通过 economy 与共同缓冲维持同步。当前 Chromium 的无同源权限沙箱不支持 module Worker，原生单行 postMessage 已实测失败；经典打包 Worker 的冻结素材、Range 与 name 实测通过，module 模式给出明确错误。任意自定义外部网络请求和不遵守公开时钟接口的作者代码仍由项目负责；本次没有宣称整片视觉或听觉内容验收。
