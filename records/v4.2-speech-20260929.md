# 4.2 语音引擎与设置交互

目标：试听不进入素材库；内置引擎随镜像提供、不可增删；自定义引擎允许网页、远程 MCP 和创作任务 AI 添加。保留现有主题，重整语音设置工作流。

## 设计

- 内置目录包含 Kokoro 中文（扩充声线）、MeloTTS 中英混合、Piper 英文多声线。模型随语音镜像下载并固定校验，运行不依赖首次联网或用户配置。单次仅驻留一个模型，CPU 推理。
- 内置目录为平台管理的固定配置，API 同样拒绝添加副本、修改、停用或删除。兼容旧 Kokoro 引擎 ID，旧重复项折叠展示，不破坏已有引用。
- 试听 API 只生成一天有效的临时音频；正式配音通过独立生成操作进入指定作品仓库。接口不再根据是否碰巧传了 repo 决定是否入库。
- 设置页先展示内置卡片和自定义卡片，试听在专用弹窗选择声线、语速、文字；自定义添加统一提供兼容 API 和上传本地模型两种方式。模型文件管理归入自定义流程。
- 远程 MCP/CLI 可管理自定义引擎、列声线、试听；容器 AI 可添加新自定义引擎及试听，保留任务权限边界和密钥隐藏。

## 模型来源

- Kokoro: https://huggingface.co/hexgrad/Kokoro-82M ，Apache-2.0。
- MeloTTS: https://huggingface.co/myshell-ai/MeloTTS-Chinese ，MIT；ONNX 转换与运行说明 https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html#vits-melo-tts-zh-en-chinese-english-1-speaker 。ONNX 英文读音受词典覆盖限制。
- Piper LibriTTS-R: https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/libritts_r/medium/MODEL_CARD ，模型仓库 MIT、训练数据 CC BY 4.0；使用 sherpa-onnx 推理，保留来源、模型卡和许可。

## OAuth 授权修复

- 实际 Chromium 复现旧版授权表单提交 `Origin: null`，返回 403；原注入测试手动传入正确 Origin，未覆盖浏览器行为。
- 授权页改用 `Referrer-Policy: same-origin`，保留同源、Cookie 与表单 CSRF 校验。CSP form-action 同时允许当前已登记 ChatGPT 回调，防止浏览器阻止 POST 后的合法回跳。
- 新浏览器测试覆盖原生表单、两种 ChatGPT 回调、取消授权、已有登录、表单编码换令牌及 MCP 工具列表；拒绝 null/异站 Origin 的检查仍保留。
- 对照官方接入要求：https://developers.openai.com/plugins/build/auth 。ChatGPT 实际账号端连接结果需用户重新连接确认；本次浏览器回调在测试端截获，避免将测试凭据发送给真实 ChatGPT。
