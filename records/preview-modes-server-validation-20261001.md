# 三种预览模式：服务器验证

验证环境：OVH 持久开发目录 main，共享代码挂载到 `frame-development:/workspace`；只运行本轮所属的独立服务器测试，不访问或清空测试数据库，不访问生产作品数据。

## 已完成

- 清单列出全部当前构建输出、项目 public 动态资源（含采样、SoundFont 和分片索引）与平台 vendor/fonts，提供真实 SHA-256、原始字节数、MIME、不可变版本 URL，以及稳定 workId/projectId。
- 原始与完整缓存模式通过原始 URL 取字节，运行时跳过媒体代理；切换模式复用同一编译会话。模式与视觉细节分离，显式压缩模式的 high 使用 preview；现有导出读取锁强制原始素材，未显式选模式的旧 high 行为兼容。
- 平台解码器/字体也使用受限快照，不在内容 URL 下暴露变化后的部署文件；能力路由不提供源码、依赖目录、其他工程或任意平台文件。
- 稳定构建文件和平台资源复用哈希及快照；失败候选只清理未发布文件。媒体快照批次等待全部并发复制结束后回滚，避免迟到复制耗尽配额。
- 音频生成器版本包含 public 内容版本，采样或 SoundFont 更新会重建旧生成器闭包，即使 audio.ts 未改。
- 媒体处理限制为两个并发任务；请求与会话各自持有等待引用。取消一个读取者保留其他读取者，取消最后读取者中止队列或 FFmpeg 子进程并清理临时文件；已完成的共享缓存保留。共享处理完成前保留输入所属会话的快照。

## 验证结果

命令在真实 FFmpeg/FFprobe 开发容器运行：

```sh
node --test tests/server/live-preview.test.mjs tests/server/live-preview-media.test.mjs tests/server/live-preview-worker.test.mjs tests/server/live-preview-bundle.test.mjs
```

结果：**32 通过，0 失败，0 跳过**，约 17.7 秒。验证包括：

- AAC 音频与 H.264 视频实际转码、FFprobe 参数和 FFmpeg 完整解码、快速定位 MP4 元数据、原始素材未改变；
- 原始和完整缓存模式不调用转码；
- 真实构建及重复热更新、资产独立更新改变生成器版本；
- 并发复制失败完整回滚、两个处理名额严格交接；
- 两个读取者的取消隔离、最后读取者取消、排队取消、实际子进程退出与无临时文件残留；
- 关闭输入所属会话时，另一读取者可以完成共享处理。

机器日志保留在忽略的 `.cache/preview-modes-server-tests-20261001.log`。本记录仅证明服务器局部实现和测试；浏览器使用体验、完整发布门禁、生产切换与上线验收由本次主任务单独验证。
