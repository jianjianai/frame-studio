# 浏览器音频迁移与首页封面修复

## 当前实现

- 根目录和三个视频内的 `production/music/` 已迁空并移除。当前乐谱、动作音效在各视频自己的 `music/`，由 `audio.ts` 接入生成音轨接口；原 MIDI、乐谱快照、旧制作说明与测量报告保存在独立的 records 中。
- 已有音乐、旁白和录音继续使用文件音轨，直接在浏览器解码、裁切、调音与混合。三个 Demo 的乐器声保留原 GeneralUser GS 2.0.3 采样、原乐谱、原配器及 spessasynth_core 4.3.22；动作音效保留原代码。没有使用新的振荡器音色替换原乐器。
- 原采样库与完整许可随各项目 `public/music/` 分发，采样库摘要为 `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`。载入时核对摘要；每项目独立保存，避免跨项目资源依赖。
- 浏览器后台线程按原事件采样时刻和 128 帧处理块生成，保留原采样器的混响、音乐电平与音效相对音量。浏览器端处理保留原高通、低通、均衡、首尾淡化及响度目标；与旧 FFmpeg 母带并非逐采样等同的承诺。
- `prepareAudio` 在播放时钟启动前准备数据；内存结果供重播、拖动、变速、循环及两种离线视频导出复用，播放节点独立释放。旧整曲 WAV、对应波形索引和 music:build 文件渲染工具退出运行链路。浏览器视频导出仍沿用现有逐帧渲染流程。
- 首页“让故事，真正动起来”右侧图片引用了已移除的 `posters/sunny-rail.webp`。现改为读取所展示项目的 poster 元数据，播放地址、标题和时长一同取自该项目；项目缺失时使用现有项目作为后备。
