## 交付行为

聊天采用紧凑头部、可搜索的历史对话和一体化输入区。模型菜单位于输入区，按命名提供商分组，支持名称/ID/提供商搜索、收藏、键盘导航和明确的不可用状态。草稿及模型选择随对话保留；提供素材、时间与选段引用，长输入可展开，中文输入法确认不触发发送。执行状态明确显示队列与停止，关闭聊天不停止服务器任务。

同提供商内切换模型保持原会话；跨提供商发送时明确新建对话，不把原上游会话绑定到另一组凭据。每个任务保存模型 ID，之后修改默认模型不会改变排队任务的选择。停用或移除所选模型后，新执行会明确失败，不静默切换。丢失确认后的相同请求仍可找回原任务；修改请求内容不得复用原幂等键。

设置提供分类导航、分类搜索和深链接。提供商共用连接地址/认证，可维护多个模型、默认模型与启用状态，手动添加或从 API 目录中选择性添加，并测试指定模型。已保存密钥不返回前端，留空保留原值，显示按钮仅显示本次输入。版本检查阻止过期表单覆盖并发修改；测试记录不覆盖已更新的凭据。模型列表变化通过 PostgreSQL 通知和 WebSocket 同步到聊天。

保留 GitHub、语音引擎、访问令牌、OAuth、工具更新及运行状态；增加浏览器级默认模型、收藏、字体与发送快捷键偏好。提供商采用停用保留历史，不增加破坏性删除入口。当前创作仍是直接执行，未把只读讨论、即时 steering、任意模型的推理强度等未实现能力做成假开关。

有本轮预览产物的消息提供独立预览入口，绑定该轮 previewTask；打开时暂停主播放器。失效或尚不可访问的产物明确报错并可重试，不替换成最新轮次。版本比较/恢复继续通过现有版本管理完成。
