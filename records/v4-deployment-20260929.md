## 本地修订验证

原生 WSL 文件系统内构建运行，`pnpm verify`：63 个单元测试、67 个 MCP/浏览器集成测试、16 个服务端测试，共 146 项通过，0 失败、0 跳过；类型、项目检查、播放器和工作台构建通过。

- 实际 Codex 0.158.0 与 Claude Code 2.1.283 CLI 对接确定性测试模型服务，完成编辑、平台重启后恢复、验证和发布预览。越界修改在应用前被拒绝。
- Chromium 真实沙箱中的 Pixi 作品通过播放、帧定位、选段、缩放和布局操作；窄屏验证画面高度及播放控制不被时间轴遮挡。
- 限速 WAV 场景首播 3,687 ms，只传输 258,048 / 5,292,044 字节；随机跳转、回退、双轨、2×、静音的观测最大漂移约 14.1 ms。
- GeneralUser 音色库 32,319,396 字节，测试作品只请求 813,080 字节的乐器包，首播 573 ms。
- 100 仓库、1,000 作品的合成索引分页查询 44 ms，断言不全仓扫描。该结果不是实际千作品大素材压测。

上述时延为受控测试结果，不保证所有网络、设备或作品具有相同时延。生产 Pixi CSP 问题和手机布局问题曾在 4.0.0 实机检查中暴露，4.0.1 使用 Pixi 无 eval 适配器并修正布局，没有放宽预览隔离。
