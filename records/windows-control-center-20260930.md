# Windows 控制中心返工

## 产品边界

完整工作台由默认浏览器打开。Windows 原生控制中心负责依赖检查、下载与修复、运行状态、重启、自动更新、日志和退出。托盘左键打开浏览器，右键进入控制中心或退出。移除内嵌工作台与 WebView2 构建依赖。

## 实现

- 原生安装向导显示阶段、下载字节和速度，支持失败重试及暂停后继续。实际工具与 Python 健康检查通过才切换版本；应用、模型、运行组件与 pnpm 包缓存分别保存。
- 原生控制中心有概览、环境、更新、诊断四页。关闭窗口收起到托盘；重复启动打开现有服务地址。持久化端口，遇到占用自动选择新端口。
- GitHub 正式 Release 自动检查与续传下载，严格验证仓库资产名和 SHA-256。校验后的 Setup 在退出或主动重启更新时安装；失败保留旧入口，支持上一版本恢复。
- 浏览器编辑保护与后台任务一起参与退出检查，冻结新任务准入后才关闭服务。语音准备独立进行，失败可重试，不阻塞工作台启动。
- 本机 CLI 状态包括安装、版本、位置与登录。Windows npm CLI 通过 Node 运行对应包入口，保留参数边界，不拼接任务命令行到 shell。
- 真实浏览器验收发现 SQLite 的 JSON `->>` 数值与 PostgreSQL 文本比较语义不同，导致成功预览不可见；新增兼容函数、整数转换与回归检查。
- 标签工作流增加原生控制中心、浏览器创作和更新安装验收，收集界面与日志证据。

- 原生安装向导与四个控制中心页面截图，在当前 Windows 200% 缩放下检查：文字、按钮和安装进度正常显示。
