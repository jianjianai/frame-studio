## 实现

- 使用固定官方 Paseo 0.10.2 / 919c737c1948c5a16220307403a82e90d3e27ea0 的完整 WebUI 与 daemon。原生消息回执、权限、终端、文件与 Git 操作复用上游；FRAME 插件提供作品上下文、准确 agent 工作目录、素材与画面引用、实时预览和候选验证/应用。
- 删除旧手写 WorkChat、旧聊天写入 API 及其独占的模型/创作偏好 UI；旧数据库历史保留，只读历史和有界摘要接续仍可用。旧 localStorage 不删除，旧偏好没有伪装成原生设置迁移。
- 原生工作树独立预览；主草稿通过范围、结构、测试、类型、实际画面/音频检查后复用现有原子发布和撤销。工作树须用原生 Git 合回主草稿再应用。
- HTTP 与 WS 透明代理，共享官方静态包及 Brotli/Gzip；实际 17 MiB 二进制 WS 完整传输，关闭时有限等待后释放未响应连接。
- 提供商与模型目录通过官方配置 RPC 热更新；凭据按所选 session 发放，daemon 不继承 FRAME master/数据库/其他提供商密钥。本机官方 CLI 环境认证按工具单独发放，并冻结私有身份散列，变更后提示创建新会话。
- FRAME 模型目录显式清空时，冻结和恢复一致委托原生目录；仍记录的旧默认模型不会限制新原生目录。非空目录的停用/移除规则继续生效，共用 Paseo selection helper 避免凭据与发送入口规则漂移。
- 同一消息的已完成原生回执优先恢复；未投递的冻结选择与当前模型不匹配会拒绝，模型切换和原生发送串行协调。
- 音频与预览 UI 复审范围按用户确认限定此次功能，详见下列独立记录。修正 Pixi 原素材语义 URL 与缓存解析，并覆盖原生 SVG/font/Worker/WASM/Range 读取路径。
