# 外部素材传输实现与验证

## 实现范围

- 共用素材传输领域实现，覆盖本机 CLI、远程 CLI、MCP 与带认证的 HTTP 二进制通道。
- 持久化分块偏移、请求去重、SHA-256、重启续传、原样发布与索引登记；保留独立授权和项目边界。
- 后台公网 URL 拉取，限流、容量与格式检查，检查所有跳转的公网解析并固定连接地址，支持查询、等待与取消。
- 新增 4 个 MCP 工具，总计 34 个。素材库识别新增字体和 MIDI 分类。
- 原有两部未跟踪影片及其他会话的工程记录保留，不修改影片源文件。

## 验证

- `pnpm verify` 实际通过：5 个项目结构检查，0 错误、0 警告；类型检查、111 项单元测试、47 项 MCP 测试、生产构建和 22 项浏览器检查通过（本次全量运行共 180 项测试）。
- 随后的代理 DNS 兼容修正通过 11/11 素材专项测试，覆盖跨进程重启续传、响应重试去重、分块内容冲突、SHA-256、格式检查、额度、只读与不同授权隔离、硬链接拒绝、过期清理、取消、真实 HTTP Range、MCP、小文件与超过 2 MiB 模型、本机和远程 CLI。
- 首次公网 URL 试拉取发现本机代理把域名解析到 `198.18.0.0/15`；保留特殊地址禁用规则，新增只针对该代理虚拟解析的公共 DoH 回退，再验证实际公网地址并固定连接。补测证明私网结果和数字特殊 IP 仍被拒绝，DNS 等待可取消。
- 使用真实公网 `https://www.w3.org/Icons/w3c_home.png` 在专属临时工程完成后台下载、校验、原样登记：1848 字节，SHA-256 `590608bf256237f22d84bbab2a0a1afc0d4f20db6350bbac2c6841f1f3e13b01`。该图片仅用于协议验证，临时工程随后清理，没有成为用户影片素材。
- 用户重启后公网返回 Cloudflare 1033；确认原服务进程 9868 已退出、原监听端口空闲、启动锁内容未改变，清理该单一失效锁，OAuth 授权数据保留。当前服务以隐藏后台进程恢复，进程和启动日志记录在本机 `.cache/mcp-service/`，不包含隧道令牌。
- 公网真实 SDK 确认 34 个工具；通过 Cloudflare 完成上传初始化、原始二进制 PATCH、分块 SHA-256、重复分块重放校验、GET 偏移查询、余下分块续传和 DELETE 取消。测试载荷为 422 字节原创 PNG，SHA-256 `08c8036661e501db6ce7ceddad368427f78f36e30875d35a0c9e3eae10395202`；只使用项目缓存，未登记到影片素材库；取消后的单一测试回执也已按身份和路径核对后清理。
- 全流程素材发布、Range 下载、跨服务重启续传、大于单块的二进制模型及 CLI 远程上传在独立测试工程实际完成；公网验收没有改动现有作品的素材索引。
