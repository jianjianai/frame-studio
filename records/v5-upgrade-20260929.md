## 已实现

### 可追溯的创作执行

审片时间、选段、可选镜头标识关联实际预览任务与源码提交。排队时固定连接、模型、端点与认证代际，不把凭据写入普通任务记录。旧预览与本轮执行版本不同，会提供独立历史参考并明确两者关系，不把旧时间码静默套到新时间轴，也不覆盖期间的新作品修改。

不兼容的模型/账号/执行身份切换不会错误复用原上游会话；使用新会话并携带有界的近期持久对话。请求幂等仍以原始请求比较，不受随后模型默认值或素材显示名变化影响。

### 结果审片和安全撤销

每轮结果关联实际修改前后提交、完整边界内的文件变化和执行器实际检查记录；用户要求的片段不伪装为已证明的全部影响范围。前后版本只播放一个沙箱播放器，历史预览不切换当前作品 Git HEAD。引用历史画面继续调整只填写草稿，不擅自发送新任务。

撤销使用隔离索引中的反向二进制补丁/三方合并，追加版本而非重写历史；保存后续不相关改动，冲突不碰正式文件与索引。工作级锁、当前提交和源码指纹防止旧界面操作覆盖新改动。文件替换及目录重命名中途异常可使用同一撤销请求恢复，不重跑 AI。

### 前端与运行反馈

预览会话、本机导出和工作面板分离。关闭面板不销毁草稿、导出状态和播放器会话；预览能力链接失败可重试现有构建。导出启动/停止回执丢失时有 15 秒有界等待，超时重新创建播放器实例终止不确定的本机编码，不把正在进行的长导出简单判定超时。迟到进度不能撤销取消状态或覆盖终态。

主要业务操作和播放器跨窗口消息复用校验契约。错误区分参数错误、冲突、依赖不可用和“请求可能已经提交”，不自动重放不确定的写操作。页面按需加载，并保留模块加载失败的可见恢复入口。

数据库通知带作品/任务等有限身份，避免不同作品无差别重查；保持持久事件游标、旧格式通知和断线后保守重新同步。同步状态只在实际变化时写入，避免查询触发通知再查询的循环。

任务显示真实排队阻塞原因，记录排队、准备、AI 执行、验证、画面编译、音频生成/缓存复用和结果发布耗时。继续复用已有分轨缓存；没有为任意动态代码声称可精确局部重算，也未承诺未经对照测试的统一性能提升。

## 复审中发现并修复的问题

1. 真实执行器暴露私有工作树 0700/0600 权限被镜像复制保留，导致 UID 1000 无法读取程序。Dockerfile 仅规范镜像内公开平台代码的读取/遍历权限，仍为 root 所有，不扩张数据目录或凭据权限。不是通过改为 root 执行 AI 来绕开问题。
2. 旧成功任务没有 `result` 字段时，结果摘要直接访问 `commit` 会使整页进入错误边界。已增加兼容处理，以真实工作台测试中的旧记录覆盖。
3. 新生命周期测试初版虚拟 JSX 模块遇到 Vite 解析、自引用和依赖预构建刷新问题，已修正测试装配；没有删去超时、重试或取消断言来绕过测试。
4. 工作台 API 夹具更新为当前主要契约，补齐排队诊断、模型配置和预览状态。仍保留缺失结果的旧任务，以检验兼容性。
