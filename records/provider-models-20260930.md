## 交付行为

新增 API 连接采用“选择模板 → 保存连接 → 自动获取目录与规格 → 勾选导入”的主流程。提供商模板预填工具及地址，支持整理粘贴的完整接口地址。目录支持搜索、新旧筛选、批量选择、明确指定默认模型、失败重试与手动添加。

模型规格按字段保留来源。API 返回优先；可关闭的公共目录仅按精确、无歧义 ID 补齐，未提供的字段保持未知。界面直接显示上下文、输出上限及能力摘要，参数页展示输入输出、模态、能力和参考价格。高级配置自动预填，手动覆盖在后续同步中保留，也可逐项恢复自动。自定义名称、模型启停状态和上游暂时未返回的旧目录项不会被同步覆盖或移除。

这些规格不冒充执行层控制：未把参考价格当作账户账单、未把最大输出当成每次强制生成长度，也未添加没有执行层保障的温度/推理强度控件。公共模型目录不代表官方账号授权范围或网关实际配置；详情见 `docs/PROVIDER-MODELS.md`。

删除入口与停用分开。提交前读取影响，需要完整名称及配置版本确认；活动任务、进行中的授权会阻止删除。服务端在提供商级锁内复核并清空凭据，保留不含密钥的内部历史标记，不删除作品、对话、任务和消息。旧页面的保存、启用、测试和新发送不能恢复已删除提供商。发起操作的浏览器清理其对应默认选择和收藏；其他提供商不受影响。
