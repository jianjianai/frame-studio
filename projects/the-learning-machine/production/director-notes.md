# 学习的机器 — 制作设计

264秒，16:9，30fps。原创三维科普短片；冷白/灰绿工作室材质、蓝绿计算信号、琥珀误差反馈，暗场仅用于片头和高潮。核心不是堆叠大字，而是让运算过程成为可以跟随的物体运动。

0–26：在计算阵列中掠行，微观数据亮起，拉远成图像与网络；以相同的发光方块匹配切入纸带。
26–48：齿轮、纸带、终端。知识写入装置，镜头跟随纸带进入规则世界。
48–76：分流门实际分拣形状，规则树展开，棋子落下，陌生物体使分流僵住。
76–114：机器沿连接展开为神经网络；前向信号、错误返回、权重变化、迭代收敛。必须能关字幕理解动作。
114–144：猫像素与实体对应，扫描提取局部边缘，特征层爆炸展开，芯片阵列辅助并行。
144–170：棋子落地、环形棋盘搜索分支、局面选择；同一颗棋子形状匹配下一个词元。
170–206：词元变成立体带状序列，代词与名词通过显著连接演示信息关联，镜头穿越权重矩阵与并行层。
206–239：预测下一个词元，反馈改善候选，微观芯片逐层装配为服务器，再拉远成为基础设施。文字、图像、波形汇流。
239–264：错误候选被审查过滤，中心网络落回人类桌面上的工具；城市与光路展开，结尾收回最初的数据方块，以提问与责任结束。

镜头至少每6–10秒有明确新信息，通过推近、升降、侧移、环绕与匹配运动改变尺度，而非静态留白拖时间。场景代码以绝对时间求值，允许冷跳和倒放。字幕采用实测语音区间并按短语拆分；世界内标签只作命名，不承载整段讲解。

配乐：原创六音主题，钢琴/钟琴起句，温暖弦乐和圆润低频递进；规则段轻机械节奏，学习段逐渐形成和声，棋局短暂停顿，注意力段节拍加密，大模型段扩展声场，结尾回归主题。音乐与声音效果独立音轨，旁白期间自动让位；转场和每次关键接触都有按绝对时间锁定的音效。

工程与审阅记录独立保存records/。音量、可播放、帧数通过不等于主观视听验收；只记录实际查看和实际听到的内容。
