# R3 制作说明

本轮用户肯定动作与运镜比前版流畅，但否决整体观感、音乐与脚本。R3重写叙事、更换完整配乐，不把R2的素材加速后重新交付。

片名《不是突然变聪明｜AI 的七十年》。156秒，32组实测解说，1080p/30fps。主线：算得快不等于看得懂，为什么长期积累最终形成大众可用的工具？

0—10.982秒：轨道计算与潦草数字构成反差，提出机器理解的困难。
10.982—29.11秒：1956及规则路线，条件判断遇到真实笔迹的例外。
29.11—52.972秒：带标签样本、错误预测、反向传播、参数改变，等待数据与计算条件。
52.972—71.908秒：2012图像识别、层级特征、成批并行，算法/数据/算力合流。
71.908—88.804秒：从识别到选择，网络、强化学习、搜索与AlphaGo。
88.804—102.82秒：句中信息的相关性、注意力与2017Transformer的并行训练结构。
102.82—132.288秒：预测下一词元、文本预训练、指令/反馈、大众对话入口和多模态；回扣长期积累。
132.288—143.672秒：自信回答可能没有证据，核验、权限与人的复核。
143.672—156秒：计算光回到笔尖，形成问题，收束到值得解决的事。

## 声音

采用 Scott Buckley《Emergent》的正式录音，CC BY 4.0。原始区间24.4—60.8、84.4—132.8、144.4—216.4秒，经两处0.4秒交叉淡化形成156秒配乐。整体音乐按叙事强弱、旁白区间和核验转折做自动化混音，结尾保留原曲较舒展的段落。没有叠加上一版鼓组或旋律。原创声音只用于少数机械接触和动作切点。

旁白更换为云扬AI合成声线，先生成、实测时间，再按句意设计动作与摄影。声音测量与主观听感分开记录；接口未回传可感知音频时，不把检测到波形写作已听完。

## 视觉和边界

工业三维可视化：冷白陶瓷、深色金属、翡翠线路、黄铜输入和节点。减少说明性卡片，使用单个机制空间承载输入、运算与结果。高光与泛光受控，标签和字幕不争主视觉。主运镜通常快速到位，跨尺度揭示稍长且承担信息；不把持续缓慢转圈作为流畅。

原理、棋局、特征、例外和数字为教学示意，不是历史硬件复刻或具体模型实测。片尾和发布说明标出配乐作者/许可、AI合成旁白。参考片没有被复制素材。详细来源与许可见 r3-sources.md；实际修改、审片、运行与导出证据在 records 中。
