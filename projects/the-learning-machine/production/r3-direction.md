# R3 · 不是突然变聪明

本轮返工针对用户新反馈：R2只有动作顺畅得到认可；观感、音乐、脚本仍不达标。R3不沿用橘猫卡通、三道题口号、循环程序配乐和大量二维文本卡片。保留项目边界和已经修复的公共播放协议，原R2及外部音频修复不覆盖。

## 叙事

主线：AI为什么走了七十年，却像突然爆发？从“算得快不等于看得懂”的反差进入。手写7作为第一个具体困难：枚举条件不足→从带标签样本学习→误差与参数→数据和算力到位→视觉与决策突破→注意力与序列→预训练、指令与大众入口→能力与可靠性的差距。研究路线并存，不声称每个阶段取代前者，也不把一场竞赛写成一切技术的唯一原因。

32个完整句组；用实测旁白决定镜头长度，而不是先留一格五秒后强塞字数。音乐主结构和画面事件共同编排。中场合力与生成系统形成一次跨尺度高潮，结尾回到“值得解决的问题”，不再使用泛泛城市拉远。

## 视觉

新镜头是工业/科学可视化，而非萌物讲课。深蓝黑、冷白陶瓷、翡翠导光、黄铜接点；真实几何阴影、倒角和受控高光。每段一个主空间，一个输入、运算与结果关系。投影文字只是名称/节点，不把旁白再抄一遍。

宏观轨道压成一根写字笔迹；笔迹进入规则机，例外使闸门失败。手写样本成为一个个带标签的实体光片，沿确定的路线进入参数阵列。误差从输出返回，参数改变后才出现改进。图像沿层级分解与重组，并行矩阵由一块铺开为整个计算场。棋局候选从多到少，落子后棋盘网格匹配为句中词元网络。词元组合、补全、指令训练和多模态融合明确区分。风险段用断开的证据链，而非把模型“道德化”。最后一束计算光变成笔尖，由问题重新启动。

摄影：主运动0.35–0.65秒；跨尺度揭示0.8–1.1秒，必须承担信息。主体就位后允许短暂阅读，不以慢慢绕圈充时长。视线落点、速度方向、物体身份连续。少用剪辑台式左右分屏，禁用与说明无关的文字堆栈。

## 音乐

停用R2的自制短正弦采样乐谱。采用Scott Buckley正式制作的《Emergent》，原曲具有推进型混合管弦、悬念合成器与末段情绪发展；按原曲乐句剪辑，保留完整和声，不把不同调性段硬拼。编辑记录原始区间、淡化、音量包络与叙事对应。鼓点不再另盖一层廉价节拍。关键选择与转场保留少量低调动作声音。语言区音乐让位，高潮处抬升，事实风险段减法并留短停顿，结尾使用原曲解决段。

## 审查

镜头检查：声音关掉能否辨认输入和变化；新知识是否由上一结果产生；动作是否指向同一个重点；放大与转场是否被叙事需要；字幕安全区与关键标注；是否有几秒钟什么都没发生。不能用工具测试通过代替艺术认可。

音乐先制作片段并尝试原生音频回读。接口若只返回链接，听觉审阅保持未完成，不将响度计结果表述为“听起来很好”。最终另行核对成片帧数、全片解码、声画时长与输入指纹。
