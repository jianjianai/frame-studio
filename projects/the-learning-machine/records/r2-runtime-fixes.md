# R2 运行修复与测试复核

全片新入口已接入。一次E2E发现两个问题：

1. 以24kHz音源交给48kHz离线上下文，在任意切段时可能出现重采样起始相位差，尾部误差最大0.0024135。现在音源按所属AudioContext采样率生成，并把事件起点、裁切边界对齐该采样网格。修后同一1.8秒尾段与两个0.9秒尾段的最大误差为5.21540641784668e-8。
2. 动作测试在104.1–104.25秒抽帧，该区间是东方候选到位后的短停顿，下一词元于104.26秒进入。测试改在104.28秒检查已编写的进入动作，不要求有意停顿也必须抖动。确定性跳转检查保留。

复测4个浏览器测试全部通过：冷跳、持续播放、暂停、逆跳与2倍速；尾段离线分块一致性；九段动作与逆向重建；全部36切点及结尾。详情见 r2-e2e-current.json。

这是工程证据，不是审美通过结论。
